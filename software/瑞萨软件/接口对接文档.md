## 1. 后端 API 总览

### 1.1 基础信息

| 项目 | 值 |
|------|------|
| 后端地址 | `http://localhost:8000` (本地开发) |
| API 前缀 | `/api/v1` |
| 健康检查 | `GET /health` |
| WebSocket 前缀 | `/api/v1/ws` |

### 1.2 API 端点汇总

#### 认证 (`/api/v1/auth`)

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| POST | `/auth/register` | 否 | 用户注册 |
| POST | `/auth/login` | 否 | 用户登录 |
| POST | `/auth/logout` | **需要** | 退出登录 |
| POST | `/auth/refresh` | 否 | 刷新 Token |
| GET | `/auth/me` | **需要** | 获取当前用户信息 |
| POST | `/auth/password/change` | **需要** | 修改密码 |

#### 机械臂 (`/api/v1/arm`)

| 方法 | 路径 | 认证 | 说明 |
|------|------|------|------|
| POST | `/arm/connect` | **需要** | 建立串口连接 |
| POST | `/arm/disconnect` | **需要** | 断开串口连接 |
| GET | `/arm/status` | **需要** | 获取机械臂实时状态 |
| POST | `/arm/command` | **需要** | 发送串口命令 |
| GET | `/arm/calibrations` | **需要** | 获取所有标定数据 |
| POST | `/arm/calibrations` | **需要** | 保存标定数据 |
| POST | `/arm/calibrations/{name}/load` | **需要** | 加载指定标定 |
| POST | `/arm/detect` | **需要** | 上传图像检测颜色 |
| POST | `/arm/clamp` | **需要** | 执行完整夹取分拣任务 |
| GET | `/arm/logs` | **需要** | 获取操作日志 |

#### WebSocket (`/api/v1/ws`)

| 路径 | 说明 |
|------|------|
| `WS /api/v1/ws/arm/status` | 机械臂状态实时推送 |
| `WS /api/v1/ws/arm/calibration` | 标定数据实时推送 |

## 2. 认证方案

### 2.1 JWT Token 机制

```
┌─────────────────────────────────────────────────────────┐
│                    认证流程                               │
│                                                          │
│  ┌──────────┐    POST /auth/login     ┌──────────────┐ │
│  │  前端    │ ────────────────────────► │   后端       │ │
│  │          │ ◄────────────────────── │              │ │
│  │          │   { access_token,       │ JWT + Redis  │ │
│  │          │     refresh_token,      │              │ │
│  │          │     expires_in }        │              │ │
│  └──────────┘                          └──────────────┘ │
│      │                                        │          │
│      │ 存储到 localStorage                    │          │
│      ▼                                        ▼          │
│  access_token  ──────────────────────────►  请求头       │
│  refresh_token ──────────────────────────►  Authorization│
│                                           Bearer <token>  │
└─────────────────────────────────────────────────────────┘
```

### 2.2 Token 存储与使用

```javascript
// 存储
localStorage.setItem('access_token', data.access_token);
localStorage.setItem('refresh_token', data.refresh_token);

// 请求头携带
headers: {
    'Authorization': 'Bearer ' + localStorage.getItem('access_token')
}

// Token 刷新流程
if (response.status === 401 && localStorage.getItem('refresh_token')) {
    await refreshAccessToken();
    // 重试原请求
}
```

### 2.3 认证依赖注入

所有需要认证的接口，使用 `Depends(get_current_active_user)` 注入当前用户：

```python
# 后端 app/deps.py
CurrentUser = Annotated[User, Depends(get_current_active_user)]
DbSession = Annotated[AsyncSession, Depends(get_db)]
```

#### POST `/api/v1/arm/command` — 发送串口命令

**请求头：**
```
Authorization: Bearer <access_token>
Content-Type: application/json
```

```json

    "params": {
        "x": 10.5,
        "y": 20.0,
        "z": -5.0,

    }
```

| `GRIPPER_OPEN` | 张开夹爪 | 无 |
| `GRIPPER_CLOSE` | 闭合夹爪 | 无 |
| `DIST` | 超声波测距 | 无 |


## 4. 前端当前状态

### 4.1 现状分析

当前前端 (`index.html`) 存在以下问题：

1. **无认证功能** — 没有登录/注册界面，所有 API 调用未携带 Token
2. **纯模拟数据** — TASKS 对象中所有数据均为硬编码，不调用任何 API
3. **无 WebSocket** — 未建立 WebSocket 连接获取实时状态
4. **无错误处理** — 没有对 API 错误响应的处理
5. **无实时更新** — 机械臂状态、工作流日志均为静态模拟

### 4.2 当前前端数据流

```
用户点击「开始执行」
        │
        ▼
  从 TASKS[id].logs 获取预定义日志
        │
        ▼
  setTimeout 逐步显示日志 (速度可调)
        │
        ▼
  更新工作流状态 (activeStep, doneSteps)
        │
        ▼
  模拟完成 (无任何 API 交互)
```

## 5. 前端改造计划

### 5.1 第一阶段：添加 API 服务层

新增 `api.js` 模块，提供统一 API 调用接口：

```javascript
const API_BASE = 'http://localhost:8000/api/v1';

// 认证 API
const authAPI = {
    login: (username, password) => POST('/auth/login', { username, password }),
    register: (username, email, password) => POST('/auth/register', { username, email, password }),
    logout: () => POST('/auth/logout'),
    refresh: (refresh_token) => POST('/auth/refresh', { refresh_token }),
    me: () => GET('/auth/me'),
};

// 机械臂 API
const armAPI = {
    connect: () => POST('/arm/connect'),
    disconnect: () => POST('/arm/disconnect'),
    status: () => GET('/arm/status'),
    command: (cmd, params) => POST('/arm/command', { command: cmd, params }),
    calibrations: () => GET('/arm/calibrations'),
    saveCalibration: (data) => POST('/arm/calibrations', data),
    loadCalibration: (name) => POST(`/arm/calibrations/${name}/load`),
    detect: (file, colors) => {
        const form = new FormData();
        form.append('file', file);
        return POST_FORM('/arm/detect', form, `?colors=${colors}`);
    },
    clamp: (color, useUltrasonic) => POST('/arm/clamp', { color, use_ultrasonic: useUltrasonic }),
    logs: (page, pageSize) => GET(`/arm/logs?page=${page}&page_size=${pageSize}`),
};
```

### 5.2 第二阶段：添加认证功能

- 添加登录页面 `login.html`
- 添加注册页面 `register.html`
- 添加 Token 管理（存储、刷新、自动注入）

### 5.3 第三阶段：对接机械臂 API

将 5 个模拟任务替换为真实 API 调用：

| 任务 | 对应后端接口 |
|------|-------------|
| 颜色识别与分拣 | `POST /arm/clamp` + `POST /arm/detect` |
| 垃圾分拣 | `POST /arm/command` (MOVE + GRIPPER) |
| 智能光照 | `POST /arm/command` (PWM 控制) |
| 人脸识别追踪 | `POST /arm/command` (MOVE) + WebSocket |
| 题目解答 | `POST /arm/detect` (OCR) |

### 5.4 第四阶段：WebSocket 实时推送

```javascript
// 连接 WebSocket 获取实时状态
function connectArmStatusWS(token) {
    const ws = new WebSocket(`ws://localhost:8000/api/v1/ws/arm/status?token=${token}`);
    ws.onmessage = (event) => {
        const data = JSON.parse(event.data);
        if (data.type === 'arm_status') {
            updateArmStatusUI(data); // 更新顶部状态栏
        }
    };
}
```

## 7. 错误处理规范

### 7.1 HTTP 状态码映射

| 状态码 | 含义 | 前端处理 |
|--------|------|---------|
| 200 | 成功 | 处理响应数据 |
| 201 | 创建成功 | 显示成功提示 |
| 400 | 请求参数错误 | 显示错误详情 |
| 401 | Token 无效/过期 | 自动刷新或跳转登录 |
| 403 | 无权限 | 显示权限不足提示 |
| 404 | 资源不存在 | 显示未找到提示 |
| 409 | 资源冲突 | 显示冲突原因（如用户名已存在）|
| 422 | 验证失败 | 显示字段验证错误 |
| 503 | 服务不可用 | 显示连接失败提示 |

### 7.2 前端统一错误处理

```javascript
async function apiRequest(url, options) {
    try {
        const response = await fetch(url, {
            ...options,
            headers: {
                'Content-Type': 'application/json',
                'Authorization': 'Bearer ' + localStorage.getItem('access_token'),
                ...options.headers,
            }
        });

        if (response.status === 401) {
            // Token 过期，尝试刷新
            const refreshed = await tryRefreshToken();
            if (refreshed) {
                // 重试原请求
                return apiRequest(url, options);
            } else {
                redirectToLogin();
            }
        }

        if (!response.ok) {
            const error = await response.json();
            throw new Error(error.detail || '请求失败');
        }

        return await response.json();
    } catch (err) {
        console.error('API Error:', err);
        throw err;
    }
}
```
