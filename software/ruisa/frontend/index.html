1 主循环（agent.py） 初始姿态 go_home → 等待唤醒（麦克风或 DEBUG 下 Enter）→ _continuous_session 内 dialogue.listen()；Web 端可用输入框或麦克风按钮（浏览器语音识别 zh-CN）。摄像头由 tasks._open_camera 按 config.CAMERA_INDEX 打开。
