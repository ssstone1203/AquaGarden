# AquaGarden 智能水族箱管理系统

一个现代化的智能水族箱管理系统前端界面，采用紫色系主题设计，具有美观的UI和良好的用户体验。

## 功能特点

### 🎨 设计特色
- **现代化UI设计**：采用紫色渐变主题，卡片式布局
- **左侧边栏导航**：固定侧边栏，方便快速切换功能
- **响应式设计**：支持各种屏幕尺寸，自适应布局
- **流畅动画**：平滑的过渡效果和交互动画
- **直观的数据展示**：清晰的传感器数据可视化

### 🚀 核心功能
1. **实时监控**
   - 双摄像头视频流显示
   - 实时传感器数据更新
   - 系统状态监控

2. **智能控制**
   - 机械臂远程控制
   - 键盘快捷键支持
   - 位置实时显示

3. **数据分析**
   - 水温、pH值、溶解氧、浊度监测
   - 历史数据趋势图表
   - 数据导出功能

4. **系统管理**
   - 用户登录认证
   - 演示/服务模式切换
   - 系统日志记录

## 使用说明

### 快速开始

1. **打开登录页面**
   - 在浏览器中打开 `login.html`

2. **登录系统**
   - 演示账号：admin
   - 演示密码：admin123
   - 点击"登录系统"按钮

3. **进入控制面板**
   - 登录成功后自动跳转到主控制面板
   - 查看实时数据和摄像头画面

### 功能操作

#### 导航菜单
- **仪表板**：查看系统概览和实时数据
- **视频监控**：管理摄像头设置
- **历史数据**：查看历史数据趋势
- **机械臂控制**：远程控制机械臂
- **警报设置**：配置系统警报
- **系统设置**：修改系统参数

#### 机械臂控制
- **鼠标控制**：点击控制面板上的方向按钮
- **键盘控制**：
  - 方向键：前后左右移动
  - W键：向上移动
  - S键：向下移动
  - 中心按钮：返回中心位置

#### 数据监控
- 自动每5秒更新一次传感器数据
- 点击刷新按钮手动更新数据
- 查看实时状态和趋势

#### 模式切换
- **演示模式**：用于展示和测试
- **服务模式**：用于实际运维

## 颜色主题

系统采用紫色系配色方案：

- **主色调**：#7c3aed (紫色)
- **辅助色**：#8b5cf6 (浅紫色)
- **温度**：#ef4444 (红色)
- **pH值**：#3b82f6 (蓝色)
- **溶解氧**：#10b981 (绿色)
- **浊度**：#f59e0b (橙色)

## 自定义配置

### 修改主题颜色

在 `styles.css` 中修改 CSS 变量：

```css
:root {
    --primary-color: #7c3aed;  /* 修改为你喜欢的颜色 */
    --primary-light: #8b5cf6;
    /* ... */
}
```

### 修改传感器阈值

在 `script.js` 中修改数据范围：

```javascript
function generateRandomData(min, max, decimals = 1) {
    // 修改 min 和 max 值来改变数据范围
}
```

## 注意事项

1. **摄像头功能**
   - 当前为演示版本，摄像头显示占位图
   - 需要后端支持才能显示真实视频流

2. **数据更新**
   - 当前使用随机数据模拟
   - 实际部署需连接真实传感器API

3. **登录验证**
   - 当前为前端验证
   - 生产环境需要后端身份验证

4. **浏览器兼容性**
   - 建议使用现代浏览器
   - 某些动画效果可能在旧浏览器不可用
