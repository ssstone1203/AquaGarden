## 自定义提示

### 修改颜色主题
编辑 `styles.css` 中的 CSS 变量：
```css
:root {
    --primary-color: #7c3aed; /* 主色 */
    --primary-light: #8b5cf6; /* 浅色 */
}
```

### 修改登录账号
编辑 `login-script.js` 中的验证逻辑：
```javascript
if (username === 'your-username' && password === 'your-password') {
    // 登录成功
}
```

## 常见问题

**Q: 为什么摄像头没有画面？**
A: 这是演示版本，需要连接实际摄像头API才能显示真实画面。

**Q: 数据是真实的吗？**
A: 当前使用模拟数据，实际部署需连接真实传感器。

**Q: 如何集成后端？**
A: 修改 script.js 中的数据获取函数，调用您的API接口。

**Q: 支持移动设备吗？**
A: 支持！界面完全响应式，可在手机和平板上使用。

## 技术支持

如遇到问题，请检查：
1. 浏览器是否为最新版本
2. JavaScript 是否已启用
3. 文件路径是否正确
4. CSS 文件是否正确加载
