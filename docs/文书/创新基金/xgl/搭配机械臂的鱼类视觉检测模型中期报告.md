# 深圳大学学生创新发展基金基础实验项目中期检查

## 项目名称

搭配机械臂的鱼类视觉检测模型

## 一、项目进度与阶段性成果说明

本项目围绕“鱼类视觉检测模型 + 机械臂执行机构 + 智慧鱼缸场景”开展研究，目标是在小型鱼缸生态系统中实现鱼类目标检测、行为状态观察、异常状态辅助判断，并进一步将视觉结果与机械臂任务联动，为自动投喂、水面漂浮物清理、鱼缸维护等场景提供基础能力。

项目启动后，本人首先完成了整体技术路线梳理，将系统拆分为鱼缸实体结构、传感器采集、视觉检测模型、机械臂控制、后端服务和前端交互六个部分。当前系统采用“一侧鱼缸、一侧盆栽”的组合形态，鱼缸侧用于鱼类养殖与视觉检测，盆栽侧用于鱼菜共生及机械臂拓展任务。系统整体设计已经从单一视觉识别任务扩展为具备感知、分析和执行能力的智能生态装置。

在硬件搭建方面，已完成鱼缸主体、传感器、水泵、机械臂、摄像头、深度相机等关键模块的采购与初步装配。鱼缸结构经过多轮调整，完成了水泵安装位置优化、传感器安装位置预留和模块支架设计。机械臂方面，已完成机械臂本体、舵机控制器及相关安装件的准备，并针对机械臂初始姿态、滑轨卡顿、松土动作等问题进行了调试和优化。当前机械臂已具备基础运动控制能力，可支撑后续视觉结果到执行动作的联动验证。

在视觉算法方面，已完成鱼类 YOLO 检测算法的初步开发。模型采用轻量化目标检测方案，重点面向鱼缸内鱼类目标识别、检测框输出和后续行为分析。训练数据来源包括公开鱼类图像数据和项目自采鱼缸视频帧，覆盖不同光照、鱼体姿态、水面反光和遮挡场景。模型在自建测试集上已能够较稳定地识别鱼类目标，并为前端视频画面叠加检测框、鱼类活跃度统计和异常状态提示提供基础。

【图片占位：鱼类 YOLO 检测效果截图】

在软件平台方面，已完成基于 Spring Boot 后端和 Vue 前端的系统原型。后端实现了登录认证、传感器数据接口、机械臂控制接口、视频流接口、WebSocket 日志推送和大模型分析接口等功能；前端实现了控制面板、摄像头画面、机械臂控制、历史数据和系统设置等页面。当前系统已可以在控制台查看传感器数据、机械臂状态和视频流画面，为中期阶段展示提供了较完整的软件基础。

【图片占位：系统前端控制台截图】

在机械臂联动方面，本人已完成机械臂控制页面和基础指令接口设计，支持方向控制、预设任务触发和运行日志反馈。项目现阶段重点验证机械臂作为执行层接收上位机任务指令的可行性，已经完成滑轨响动卡死问题、机械臂初始姿态问题和挖土动作优化。后续将继续推进鱼类检测结果与机械臂投食、捞取水面漂浮物等任务的闭环联动。

综合来看，项目目前已完成总体架构设计、关键硬件准备、软件平台原型、鱼类检测算法初版和机械臂基础控制验证，整体进度符合中期阶段预期。

## 四、项目难点

项目当前主要难点集中在鱼缸视觉环境复杂、鱼类目标运动随机、机械臂执行精度要求高、软硬件联调链路长几个方面。

第一，鱼缸视觉场景存在水面反光、玻璃折射、气泡、背景装饰干扰和光照变化等问题。鱼类在水中快速游动时，目标会出现运动模糊、局部遮挡和姿态变化，导致检测框稳定性下降。尤其在鱼体颜色与背景接近、鱼游到缸壁边缘或水草遮挡区域时，模型容易出现漏检或误检。后续需要继续补充真实场景数据，并针对水面反光、低照度和遮挡情况进行数据增强。

第二，鱼类检测模型与机械臂执行之间还存在坐标转换和任务定义问题。鱼类检测结果通常是二维图像中的目标框，而机械臂执行需要三维空间中的位置、姿态和安全路径。鱼本身是运动目标，不适合作为机械臂直接接触对象，因此现阶段更合理的联动方式是根据鱼类状态触发投食、提醒或环境调节，而不是直接抓取鱼类。如何将视觉结果转化为可靠、可执行、低风险的机械臂任务，是项目后续的关键问题。

第三，机械臂在鱼缸附近执行任务时需要考虑安全边界。机械臂运动不能碰撞鱼缸玻璃、传感器、水管和盆栽结构，也不能因为误动作导致水体扰动过大。当前机械臂基础动作已经能够运行，但在自动投食、捞取漂浮物等任务中仍需要进一步优化路径规划、末端执行器结构和异常停止机制。

第四，软硬件联调涉及后端、前端、视觉算法、串口通信、机械臂控制、传感器采集等多个模块。单个模块可以独立运行时，整机联调仍可能出现通信延迟、视频卡顿、接口状态不同步、任务日志不完整等问题。后续需要继续完善模块边界和异常处理机制，提高系统连续运行能力。

第五，数据集规模仍有提升空间。当前鱼类检测模型已经完成初版训练和测试，但自采数据量、鱼类种类、光照条件、背景复杂度仍不足以覆盖全部实际场景。后续需要通过固定摄像头持续采集视频帧，建立更完整的数据集，并对训练集、验证集和测试集进行规范划分。

## 六、后期计划

后续阶段，项目将围绕模型优化、机械臂联动、系统稳定性和成果整理四条主线推进。

在视觉模型方面，继续扩充鱼类检测数据集，重点补充不同光照、水面反光、鱼体遮挡、快速游动和复杂背景场景。对现有 YOLO 检测模型进行迭代训练，优化检测框稳定性和实时推理速度。后续计划在视频流中加入检测框叠加、鱼类数量统计、活跃度估计和异常行为提示，使视觉模型不仅能“检测到鱼”，还能为系统判断鱼类状态提供依据。

【图片占位：后续视频流叠加检测框效果图】

在机械臂联动方面，优先完成风险较低、展示效果明确的任务，包括自动投食、捞取水面漂浮物和盆栽区松土。自动投食任务可由鱼类活跃度或定时策略触发，机械臂完成取放或摇动投食容器；水面漂浮物清理任务可结合视觉分割结果和深度信息，控制机械臂移动到目标附近并执行夹取；松土任务则继续优化已有动作，使其更加平稳、安全和可重复。

在系统集成方面，继续完善 Spring Boot 后端、Vue 前端和 Python 视觉/机械臂 Agent 的协同。重点优化视频流卡顿、任务状态同步、WebSocket 日志、异常恢复和默认数据机制。后续将把鱼缸视频目标检测框接入前端页面，使用户能够在控制台中直接看到检测结果，并结合传感器数据形成综合分析。

在硬件调试方面，继续完成鱼缸摄像头固定、深度相机驱动、机械臂与开发板通信、补光和防反光处理。对机械臂运动范围进行安全边界标定，避免执行过程中碰撞鱼缸、管线和传感器。对水泵、传感器和机械臂进行连续运行测试，记录运行日志和异常情况。

在成果整理方面，完成中后期测试数据、算法指标、系统截图、样机照片和演示视频的整理。计划形成一份完整结题报告、一套可运行软件系统、一套智慧鱼缸与机械臂样机、若干算法测试截图和一段系统演示视频，为项目结题和后续比赛申报提供材料基础。

## 八、补充说明

本项目的创新点在于将鱼类视觉检测模型与机械臂执行机构结合，面向小型智慧鱼缸场景构建具备感知、判断和执行能力的生态管理系统。与普通鱼缸监控或单纯目标检测项目相比，本项目不仅关注鱼类目标识别，还尝试将检测结果用于后续自动投食、异常提醒、漂浮物清理和生态状态分析，使视觉模型具备更明确的实际应用价值。

当前项目仍处于中期迭代阶段，部分功能已经完成原型验证，部分功能仍在联调优化中。鱼类检测模型已经具备初步可用效果，但还需要更多真实场景数据提升鲁棒性；机械臂控制已经完成基础调试，但与视觉检测结果的闭环联动仍需进一步验证；软件平台已经具备展示和控制能力，但视频检测框叠加、任务状态同步和长期运行稳定性仍需优化。

后续本人将以“可稳定演示”为核心目标，优先打通从鱼缸视频采集、鱼类检测、前端显示到机械臂任务触发的完整链路。在保证安全和稳定的前提下，再逐步扩展更多功能，如水质数据融合分析、鱼类活跃度评估、大模型状态总结和语音交互控制等。
