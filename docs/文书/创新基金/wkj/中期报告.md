# 基于嵌入式开发智能鱼缸的 Web 应用开发展示中期报告

## 项目名称

基于嵌入式开发智能鱼缸的 Web 应用开发展示

## 一、项目进度与阶段性成果说明

本项目围绕“智能鱼缸 + 嵌入式感知控制 + Web 可视化展示”展开，目标是构建一个能够采集鱼缸环境数据、控制执行器、展示设备运行状态并支持远程交互的综合实验平台。项目整体分为需求分析与方案设计、硬件选型与结构设计、嵌入式模块调试、后端服务与通信接口开发、Web 前端展示开发、系统联调与成果展示六个阶段。

截至中期检查阶段，项目已完成以下工作：

1. 完成系统总体方案设计。项目采用“嵌入式硬件采集与控制 + Python/FastAPI 任务桥接 + Spring Boot 网关 + Vue Web 前端”的分层结构。嵌入式侧负责传感器采集和外设控制，后端侧负责接口转发、状态管理、日志和视频流代理，Web 端负责交互展示和操作入口。
2. 完成鱼缸结构初版与迭代设计。已建立鱼缸三维模型，设计了养鱼区与植物种植区的分区结构，并预留 PCB、水泵、温湿度传感器、水下温度传感器、土壤湿度传感器、水质传感器等安装位置。后续又根据水泵“左进右出”的实际接管方向调整安装位置，并为新增模块设计夹持式支架。
3. 完成主要实验材料采购与整理。已采购鱼缸、机械臂、摄像头、瑞萨开发板、J-Link 仿真器、水泵、pH 传感器、水质检测模块、水下温度传感器、温湿度传感器、土壤湿度传感器、压力传感器、LED 模块、电源与线材等，并建立采购清单和票据材料。
4. 完成部分嵌入式模块调试准备与任务拆解。已明确压力传感器 ADC 采样、水质传感器串口通信、SHT30 温湿度传感器 I2C 通信、水下温度传感器读取、水泵驱动与 12V 稳压供电等调试任务。相关工程已按瑞萨 MCU 开发流程在 Keil、RASC/FSP 环境中组织。
5. 完成 Web 应用原型开发。前端采用 Vue 3 + Vite，实现了智能设备交互界面，包括对话输入、快捷任务按钮、麦克风语音输入、任务执行状态、后端日志展示、摄像头实时画面弹窗、WebSocket 连接状态提示等功能。
6. 完成 WebSocket 通信模块开发。前端已封装 AgentWS 模块，对接 `/api/v1/ws/agent/chat`，支持消息发送、调试唤醒、心跳、断线重连、任务开始、任务日志、任务完成、任务错误、摄像头预览等事件。
7. 完成后端代理链路设计。Spring Boot 网关已用于将浏览器对 `/api/v1/ws/agent/chat` 与 `/api/v1/camera/mjpeg` 的请求代理到 Python FastAPI 服务，使 Web 端可以在统一路径下访问智能任务、摄像头流和后端状态。
8. 完成阶段性展示能力。当前系统已经具备通过浏览器界面演示任务触发、状态回传、日志输出和摄像头画面展示的能力，为后续接入真实鱼缸数据和控制设备打下基础。

目前项目进度总体符合中期计划，已从单纯硬件验证推进到“硬件结构 + 嵌入式调试 + Web 展示平台”并行联调阶段。

## 二、实验资源使用情况

项目开展过程中主要使用了以下实验资源：

1. 嵌入式开发资源：使用瑞萨 RA 系列开发板、J-Link 调试器、Keil、RASC/FSP 配置工具进行 MCU 工程创建、下载调试、外设配置与传感器验证。
2. 电子测试与焊接资源：使用万用表、电源模块、杜邦线、端子线、稳压模块、面包板/转接线等完成传感器接线、电源测试和外设联调。
3. 结构设计与加工资源：使用 SolidWorks 等工具完成鱼缸、隔板、PCB 固定结构、摄像头支架、TDS 支架、USB 灯支架、电源模块支架等三维模型设计，并结合 3D 打印/加工件进行实物装配验证。
4. 软件开发资源：使用本地开发电脑完成 Vue 前端、Spring Boot 网关、Python 后端桥接脚本和项目文档编写；使用 Git 管理代码与文档。
5. 展示与调试资源：使用摄像头、机械臂、鱼缸实物、传感器模块和 Web 浏览器进行系统演示，验证前端页面、WebSocket 事件和设备状态展示效果。

中期阶段实验资源使用频率较高，主要集中在硬件接线调试、结构安装验证和 Web 应用联调三个方向。每周根据模块推进情况开展 2 至 4 次集中调试，单次调试约 2 至 4 小时，累计实验与开发时间约 60 小时以上。

## 四、项目难点

目前项目存在的主要问题与困难如下：

1. 硬件接口多，联调复杂。系统涉及 ADC、UART、I2C、GPIO、PWM/电机驱动等多类接口，不同传感器供电电压、通信协议和采样周期不同，统一接入 MCU 需要较多调试工作。
2. 鱼缸场景对防水和稳定性要求高。水泵、水管、传感器探头、电源线和控制板需要同时安装在鱼缸附近，必须处理好防水、防潮、线束固定和安全供电问题。
3. 传感器数据需要校准。pH、水质、水下温度、土壤湿度和压力数据受环境、安装位置、供电稳定性影响明显，直接读取的原始数据不能完全代表实际状态，需要进行标定、滤波和异常值处理。
4. Web 端与真实硬件状态同步仍需加强。当前 Web 应用已完成通信和展示原型，但后续需要将模拟状态、任务日志和真实 MCU 采集数据进一步统一，避免前端展示与硬件状态不一致。
5. 多服务启动链路较长。当前系统涉及 Python FastAPI、Spring Boot 网关和 Vue 前端三个服务，启动顺序、端口配置、代理路径和 WebSocket 连接需要统一配置，后续需要进一步简化演示部署流程。
6. 结构迭代会影响软件调试。鱼缸支架、传感器安装位置、水泵管路走向调整后，会影响传感器读数稳定性和执行器控制效果，需要硬件结构与软件算法同步迭代。

## 六、后期计划

后续项目将围绕“真实数据接入、稳定控制、Web 展示完善和成果材料整理”继续推进，计划如下：

1. 完成嵌入式传感器驱动调试。重点完成压力传感器 ADC 采样、水质传感器 UART 通信、SHT30 I2C 采集、水下温度传感器读取、土壤湿度数据采集等模块，并统一输出结构化数据。
2. 完成水泵与执行器控制。根据 DRV8870 电机驱动和 12V 供电要求，完成水泵启停、流量测试和管路稳定性验证，并在 Web 端增加控制入口与状态反馈。
3. 完成数据处理与阈值判断。对温度、湿度、pH、水质、土壤湿度等数据进行滤波、校准和异常检测，形成鱼缸环境状态评价逻辑。
4. 打通 MCU 与上位机通信。通过串口或其他稳定通信方式将嵌入式采集数据上传至 Python/Spring 后端，再由 WebSocket 或 REST API 推送到前端页面。
5. 完善 Web 应用展示。将当前任务式交互界面扩展为智能鱼缸仪表盘，展示水温、环境温湿度、pH、水质、土壤湿度、水泵状态、灯光状态、摄像头画面和告警信息。
6. 优化系统部署流程。整理 Python、Spring Boot、Vue 三端启动脚本和配置说明，降低演示时的环境依赖和启动复杂度。
7. 完成整机联调与演示视频。基于实物鱼缸完成传感器、执行器、Web 页面、摄像头画面和日志回传的完整演示，并录制展示材料。
8. 完成结题文档。整理项目背景、技术路线、硬件设计、软件架构、实验数据、成果展示、问题总结和后续改进方向。

## 七、团队协作

项目组成员围绕硬件、嵌入式、Web 软件、结构设计和文档展示进行了分工协作。硬件方向负责传感器选型、接线、供电、调试和鱼缸实物装配；嵌入式方向负责瑞萨 MCU 工程创建、外设驱动配置、数据采集与串口通信；软件方向负责 Vue 前端界面、WebSocket 通信、Spring Boot 网关和 Python 任务桥接；结构方向负责鱼缸模型、支架、隔板、传感器安装位置和装配验证；文档方向负责采购清单、任务记录、中期报告和展示材料整理。

项目实施过程中，团队通过线下集中调试和线上文档协作推进任务。遇到问题时，成员会围绕接线方案、模块协议、Web 接口、结构安装和展示效果进行讨论，逐步将问题拆解为可验证的小任务。通过本阶段实践，团队成员提升了嵌入式外设调试、Web 前后端协作、硬件结构设计、工程文档整理和系统集成能力，也认识到跨硬件与软件系统开发需要更加重视接口规范、测试记录和阶段性验证。
