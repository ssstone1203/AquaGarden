# 瑞萨杯决赛设计报告模板 — 格式要求整理

依据：`docs/文书/瑞萨杯/国赛/2026年信息科技前沿专题赛（瑞萨杯）决赛设计报告模板.doc`

---

## 1. 总体要求


| 项目   | 要求                        |
| ---- | ------------------------- |
| 纸张   | A4                        |
| 默认正文 | **宋体、五号、单倍行距**（除标题等另有规定外） |
| 正文字数 | 决赛不超过 **15000 字**         |


报告内容应至少包括：作品概述、作品设计与实现、作品测试与分析、创新性说明、总结；并含中英文对照题目与摘要，以及附录（源代码和程序清单、扩展应用系统电路图、应用资料与参考文献目录等）。

---

## 2. 中文摘要 / 关键词


| 元素      | 字体      | 字号  |
| ------- | ------- | --- |
| 「摘 要」标题 | 方正小标宋简体 | 小四  |
| 摘要正文    | 楷体      | 五号  |
| 「关键词」标签 | 黑体      | 五号  |
| 关键词内容   | 楷体      | 五号  |


- 摘要：简要说明动机、功能、特性、创新处、实用性，限 **600 字以内**（约 1 页）。
- 关键词：至少有一个有工程背景；须在篇名和摘要中出现过；不用缩写词。

---

## 3. 英文题目 / Abstract / Keywords


| 元素                     | 字体              | 字号  | 其他  |
| ---------------------- | --------------- | --- | --- |
| 英文题目（Name of the Work） | Times New Roman | 四号  | 居中  |
| Abstract 正文            | Times Bold      | 五号  | —   |
| 「Keywords」标签           | Times New Roman | 五号  | —   |
| Keywords 内容            | Times Bold      | 五号  | —   |


---



## 4. 正文各级标题（各章通用）

适用于：作品概述、作品设计与实现、作品测试与分析、创新性说明、总结。


| 层级              | 示例          | 字体  | 字号  | 段落间距              |
| --------------- | ----------- | --- | --- | ----------------- |
| 一级标题            | 作品概述        | 宋体  | 四号  | 段前 8 磅、段后 8 磅     |
| 二级标题            | 1.1 …       | 宋体  | 小四  | 段前 0.2 行、段后 0.2 行 |
| 三级标题            | 1.1.1 …（可无） | 黑体  | 五号  | 段前 3 磅、段后 2 磅     |
| 正文（含正文 1～4 级条目） | —           | 宋体  | 五号  | 单倍行距（总体规定）        |


---



## 5. 附录与参考文献


| 元素          | 字体  | 字号  |
| ----------- | --- | --- |
| 「参考文献」标题/标签 | 黑体  | 五号  |
| 参考文献条目正文    | 宋体  | 小五  |


- 著录细则可参考国标 **GB/T 7714**。
- 附录可含：源代码和程序清单、扩展应用系统电路图、应用资料与参考文献目录。

---



## 6. 图


| 项目   | 要求                              |
| ---- | ------------------------------- |
| 图片格式 | `.jpg` / `.bmp` / `.tif`        |
| 内容要求 | 应为自己作品的准确结构、电路等图，宜高分辨率          |
| 图题位置 | 图下方；图片与图题均居中                    |
| 图题   | 小四号宋体                           |
| 图中文字 | 小四号宋体                           |
| 编号   | 阿拉伯数字连续编号，与正文一致（图1、图2…）         |
| 分图   | 用 (a)(b)… 编分图号                  |
| 图文一致 | 图中量、符号、单位等与正文统一；外文尽量译中文（专有名词除外） |
| 位置   | 一般置于文中提及之后，不宜远离相关文字             |


---



## 7. 表


| 项目   | 要求                      |
| ---- | ----------------------- |
| 表题位置 | 表上方、居中                  |
| 表题   | **小四号黑体**               |
| 表内文字 | **小四号宋体**               |
| 表本身  | 居中                      |
| 编号   | 阿拉伯数字连续编号（表1、表2…），与正文一致 |
| 注释   | 可注于表下，注前加「注：」           |
| 位置   | 一般置于文中提及之后，不宜远离相关文字     |


---



## 8. 公式


| 项目   | 要求                                            |
| ---- | --------------------------------------------- |
| 排版   | 另起一行、居中；较长公式可换行，优先在等号处对齐；不能在等号换行时，可在 ＋、－ 等处断开 |
| 编号   | 重要公式或后文需提及的公式可编号，如（2），写在右边行末，中间不加虚线           |
| 变量   | 斜体                                            |
| 常量   | 正体                                            |
| 向量   | 斜体加粗                                          |
| 矩阵字母 | 黑斜体（矩阵中的元素仍用白斜体）                              |


下标、单位符号等正斜体细则以模板「公式」专节为准（如单位 b/B、b/s、B/s 等）。符号说明格式须统一。
