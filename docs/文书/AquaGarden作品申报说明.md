# AquaGarden——基于多模态 AI 机械臂的居家实时调度水陆生态圈

本文稿按竞赛/申报材料常见栏目整理，可按实际硬件型号与实现进度删改标注。

---

## 1. 作品简介

**AquaGarden** 面向居家场景，构建「水（智能鱼缸）—陆（智慧盆栽）」一体化的小型生态圈：通过**多路传感器**实时掌握水质（如 pH、水温、浑浊度等）、环境与土壤状态，配合**水泵与水路**实现养水与植物浇灌的联动；以**多模态信息**（视频、水质、行为与状态等）为输入，结合**深度学习目标检测**与**机械臂执行**，完成漂浮物清理、叶面/病叶处理、辅助投食或采样等任务；另提供 **Web 端可视化与远程交互**（含用户认证、实时数据与日志），实现**居家环境下的实时感知、调度与执行闭环**，提升养护效率与科普展示价值。

## 3. 作品安装说明

### 环境要求

- **后端**：JDK 17+、Maven 3.8+；默认服务端口 **8090**（可在 `application.properties` 修改）。
- **前端**：Node.js（建议 LTS）、npm；进入 `software/fish-arm/front-vue`，执行 `npm install`，开发模式 `npm run dev`；生产构建 `npm run build`，按 `vite.config.js` 配置后端代理或 `VITE_API_BASE`。

### 运行顺序（典型）

1. 部署 SQLite 数据库路径（首次运行会生成 / 初始化数据，见 `software/fish-arm/backend-spring/docs/PROJECT-STRUCTURE.md`）。
2. 启动后端：`mvn spring-boot:run`（或打包 `jar` 后 `java -jar`）。
3. 启动前端并在浏览器访问；使用系统分配的账号登录（若沿用演示账号，以项目当前 `DataInitializer` / 文档为准）。

### 嵌入式与机械臂

- 按 PCB 与传感器接线图连接 pH、温度、浊度、土壤湿度等模块；水泵与机械臂电源隔离、共地规范布线。
- 机械臂与上位机通信方式（串口 / 网络 / ROS2 等）以现场配置为准，保证与后端或边缘节点的协议一致。

### 注意

摄像头、USB 设备权限在 Linux 开发板上需加入相应 `udev` 或用户组；生产环境请修改默认密钥与 JWT 配置。

## 5. 设计思路

1. **问题定义**：家庭养鱼与养植分立、劳动强度高；水质恶化与残饵漂浮难以及时处理。
2. **总体架构**：**感知层**（多传感器 + 视觉）→ **决策层**（规则调度 + 多模态融合 / 大模型或 Agent，可选）→ **执行层**（水泵、灯光、机械臂等）→ **交互层**（Web 与可选语音 / 对话）。
3. **水陆协同**：富营养水体经处理后用于植物灌溉，形成**小型物质循环**，降低换水与施肥频率。
4. **机械臂定位**：在高风险或精细操作（清理、叶面、采样）时**替代人手**，并与视觉检测结果绑定，减少误操作。
5. **软件工程**：前后端分离、JWT 鉴权、WebSocket 推送日志或状态，便于调试与演示。

## 6. 设计重点难点

### 重点

- 多源数据同步（传感器采样周期、视频帧率、控制指令）与**实时性**平衡。
- **水—陆**水路设计：防倒流、防干烧、水位与水泵联锁。
- 机械臂在**潮湿、反光**环境下的标定与可重复抓取。

### 难点

- 水质传感器**标定与长期漂移**，多参数联合告警策略。
- 视觉与机械臂的**手眼标定**，目标遮挡与水面反光对检测的影响。
- 嵌入式算力与检测模型大小的折中；**安全性**（限位、急停、过流保护）。
- Spring Security、WebSocket 与跨域在生产环境的一致配置。
