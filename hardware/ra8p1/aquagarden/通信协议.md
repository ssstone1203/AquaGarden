# AquaGarden RA8P1 UART 通信协议 v1

> **状态**：v1 已确认并冻结；固件实现按本版本执行  
> **参考**：`hardware/demo_wyr/FreeRTOS drive/data_merge/src/frontend_control_protocol.md`（下行）、`Communicate_Task_entry.c` UART 模式（上行）  
> **适用范围**：`hardware/ra8p1/aquagarden/` 目标工程

物理接口：**UART**（波特率由 RASC 配置，建议与 `data_merge` 一致 **115200 8N1**）

## 1. 协议变更表（相对 data_merge / frontend_control_protocol）

| 类别 | 保留 | 修改 | 新增 | 删除 |
|---|---|---|---|---|
| **下行帧格式** | `5A A5 LEN CMD PAYLOAD CRC16` | — | — | 旧版 `55 AA` 38 字节下行泵命令（RA8P1 不再支持） |
| **上行帧格式** | `55 AA VER SEQ LEN PAYLOAD(30) CRC16` 外壳 | `VER` 升为 `0x02`；payload 布局重定义 | 雾化器/USB 灯状态字段 | 3 路压力字段 |
| **下行 CMD** | `0x01`~`0x07`（水泵、土壤、联动） | `0x03`：WQI → TDS（**NTU** u16） | `0x08` USB 灯、`0x09` 雾化器 | — |
| **上行语义** | 时间戳、温湿度、水温、土壤、水泵、alarm、retry | 字节 17 起：WQI→**TDS NTU** u16；alarm 位重新定义 | 雾化器/USB 灯状态 | 压力数据与压力 alarm |
| **联动 enable_bits** | bit0 土壤、bit1 水温 | bit2：WQI → **TDS 过低联动** | — | — |

## 2. 通用约定

### 2.1 CRC16（Modbus）

- 多项式：`0xA001`
- 初值：`0xFFFF`
- 计算范围：从帧首 SYNC0 到 payload 末字节（**含** SYNC，**不含** CRC 本身）
- 字节序：CRC 低字节在前（`CRC16_LO CRC16_HI`）

### 2.2 字节序

- 多字节整数默认 **小端（LE）**，除非另有说明
- 温度类定点：`(物理值 × 10)` 后按 **int16 LE** 传输

## 3. 下行：控制帧（Host → MCU）

### 3.1 帧格式

```
| 偏移 | 长度 | 字段        | 值 / 说明                          |
|------|------|-------------|-------------------------------------|
| 0    | 1    | SYNC0       | `0x5A`                              |
| 1    | 1    | SYNC1       | `0xA5`                              |
| 2    | 1    | LEN         | `1 + payload_len`（含 CMD 1 字节）   |
| 3    | 1    | CMD         | 命令码                              |
| 4    | N    | PAYLOAD     | 命令参数                            |
| 4+N  | 2    | CRC16       | Modbus CRC16，低字节在前             |
```

### 3.2 水泵命令

#### `0x01` Set Manual Pump（遗留，仍支持）

- Payload：`[manual_mode, pwm_percent]`
- `manual_mode`：`0` = 自动联动，`1` = 手动
- `pwm_percent`：`0..100`（固件对 >100 钳位为 100）

行为：

- `manual_mode=1, pwm>0` → 手动模式运行，给定 PWM
- `manual_mode=1, pwm=0` → 手动模式停止
- `manual_mode=0` → 恢复自动联动模式

#### `0x04` Pump Start（推荐用于「启动」按钮）

- Payload：可选 `[pwm_percent]`，可为空 `[]`
- 行为：强制手动开；若带 payload 则更新 PWM；若当前手动 PWM 为 0，默认设为 `60%`

#### `0x05` Pump Stop（推荐用于「停止」按钮）

- Payload：`[]`
- 行为：强制手动开，PWM 置 `0`

#### `0x06` Set Pump PWM（推荐用于速度滑条）

- Payload：`[pwm_percent]`
- 行为：强制手动开，设置 PWM `0..100`

#### `0x07` Set Pump Auto

- Payload：`[]`
- 行为：退出手动，恢复传感器联动逻辑

### 3.3 传感器 / 联动配置

#### `0x02` Soil Config

- Payload：`[threshold, hysteresis]`
- 二者均钳位到 `0..100`（单位：%）

#### `0x03` Linkage Config（**相对旧版已修改**）

- Payload：`[enable_bits, temp_high_i16_lo, temp_high_i16_hi, tds_low_lo, tds_low_hi]`
- `enable_bits`：
  - bit0：土壤湿度联动
  - bit1：水温过高联动
  - bit2：**TDS 过低联动**（旧版为 WQI bit2，已废弃）
- `temp_high`：有符号 int16，`×10` 传输，固件钳位到 `0.0..100.0` ℃
- `tds_low`：uint16，单位 **NTU**（浊度），固件钳位到 `0..65535`（曲线有效区间约 0～1400 NTU，见 `TDS标准曲线.png`）

### 3.4 执行器命令（**新增**）

#### `0x08` USB Light Set Mode

- Payload：`[mode]`
- `mode`：与 `usb_light_mode_t` 枚举一致（`0..26`），定义见下表
- 行为：调用 `usb_light_set((usb_light_mode_t)mode)`
- 若 `mode` 超出范围，固件返回忽略（或记 `COMM_RX` 类错误，实现时二选一并在说明文档注明）

| mode | 含义 |
|------|------|
| 0–7 | RED/YELLOW/GREEN/…/BLUE **ON**（含 RED_ON_HORN） |
| 8–15 | 各色 **SLOW** 闪烁 |
| 16–23 | 各色 **FAST** 闪烁 |
| 24 | HORN_ON |
| 25 | HORN_OFF |
| 26 | OFF（全关） |

#### `0x09` Atomizer Set

- Payload：`[state]`
- `state`：`0` = 关（`atom_off()`），`1` = 开（`atom_on()`）
- 其他值忽略

### 3.5 前端快捷映射

| UI 操作 | 发送命令 |
|---------|----------|
| 水泵启动 | `0x04`（可选带当前 PWM） |
| 水泵停止 | `0x05` |
| PWM 滑条 | `0x06` + 滑条值 |
| 自动/手动切换 | 自动 → `0x07`；手动 → `0x04` |
| USB 灯模式 | `0x08` + mode |
| USB 灯关闭 | `0x08` + `26`，或单独封装发送 `0x08 0x1A` |
| 雾化器开/关 | `0x09` + `1` / `0` |

## 4. 上行：传感器数据帧（MCU → Host）

MCU 每 **250 ms** 主动发送一帧。

### 4.1 帧格式

```
| 偏移 | 长度 | 字段           | 值 / 说明                    |
|------|------|----------------|------------------------------|
| 0    | 1    | SYNC0          | `0x55`                       |
| 1    | 1    | SYNC1          | `0xAA`                       |
| 2    | 1    | VER            | `0x02`（v1 协议）            |
| 3    | 1    | SEQ            | 递增序号（uint8 回绕）       |
| 4    | 2    | PAYLOAD_LEN    | 固定 `0x1E 0x00`（30）       |
| 6    | 30   | PAYLOAD        | 见 §4.2                      |
| 36   | 2    | CRC16          | Modbus CRC16，低字节在前      |
```

**总长度：38 字节。**

> 解析方必须先检查 `VER == 0x02`，再按下列布局解码。`VER == 0x01` 为旧版 data_merge 布局（含 WQI/压力），RA8P1 固件**仅发送** `0x02`。

### 4.2 PAYLOAD 布局（30 字节，VER=0x02）

| Payload 偏移 | 长度 | 字段 | 类型 | 说明 |
|-------------|------|------|------|------|
| 0 | 4 | `timestamp_ms` | u32 LE | 系统 tick 或融合时间戳 |
| 4 | 2 | `air_temp` | i16 LE | 气温 ×10，℃ |
| 6 | 2 | `air_humi` | i16 LE | 空气湿度 ×10，%RH |
| 8 | 2 | `water_temp` | i16 LE | 水温 ×10，℃ |
| 10 | 1 | `soil_moisture` | u8 | 土壤湿度 0..100 % |
| 11 | 2 | `tds_ntu` | u16 LE | TDS/浊度 **NTU**（由 ADC 电压经标准曲线换算，见 `需求.md`） |
| 13 | 1 | `pump_pwm` | u8 | 水泵当前 PWM 0..100 % |
| 14 | 1 | `need_watering` | u8 | 联动需浇水标志 0/1 |
| 15 | 1 | `atomizer_state` | u8 | 0=关，1=开 |
| 16 | 1 | `usb_light_mode` | u8 | 当前模式 0..26；未初始化=`0xFF` |
| 17 | 3 | `reserved` | u8×3 | 填 `0` |
| 20 | 4 | `alarm_flags` | u32 LE | 见 §4.3 |
| 24 | 2 | `air_retry_count` | u16 LE | 温湿度传感器重试计数 |
| 26 | 2 | `tds_retry_count` | u16 LE | TDS 采样重试计数 |
| 28 | 2 | `uwt_retry_count` | u16 LE | 水温传感器重试计数 |

### 4.3 alarm_flags（VER=0x02）

| Bit | 名称 | 说明 |
|-----|------|------|
| 0 | `SOIL_SENSOR_FAULT` | 土壤传感器故障 |
| 1 | *(保留)* | 填 0 |
| 2 | `AIR_READ_FAIL` | 温湿度读取失败 |
| 3 | `TDS_READ_FAIL` | TDS 读取/换算失败 |
| 4 | `UWT_READ_FAIL` | 水温读取失败 |
| 5 | `WATER_TEMP_HIGH` | 水温超过联动阈值 |
| 6 | `TDS_LOW` | TDS 低于联动阈值（且最近一次读数有效） |
| 7 | *(保留)* | 填 0 |
| 8 | `COMM_RX_ERROR` | 下行帧 CRC/格式错误累计 |
| 9 | `USB_LIGHT_FAULT` | USB 灯命令发送失败 |
| 10 | `ATOMIZER_FAULT` | 雾化器控制失败（可选，未实现则恒 0） |
| 11–31 | *(保留)* | 填 0 |

## 5. 示例

### 5.1 下行：水泵启动（默认 60%）

```
5A A5 01 04 CRC_LO CRC_HI
```

### 5.2 下行：联动配置（土壤+水温+TDS 均启用；水温上限 28.0℃；TDS 下限 300 NTU）

```
enable_bits = 0x07
temp_high   = 280 (28.0℃ ×10)
tds_low     = 300  (NTU)

Payload: 07 18 01 2C 01
LEN = 1 + 5 = 6

帧: 5A A5 06 03 07 18 01 2C 01 [CRC16]
```

### 5.3 下行：USB 灯绿色常亮（mode=2）

```
5A A5 02 08 02 [CRC16]
```

### 5.4 下行：雾化器开启

```
5A A5 02 09 01 [CRC16]
```

## 6. 实现检查清单

固件实现完成后，逐项验证：

- [ ] 下行仅接受 `5A A5` 帧；错误帧递增 `COMM_RX_ERROR`
- [ ] 上行 `VER=0x02`，250 ms 周期发送
- [ ] 无压力传感器相关字段与 alarm 位
- [ ] TDS 为 **NTU** u16；换算式 $y=66.71x^3-127.93x^2+428.7x$（x 为 0～3 V）；联动 `0x03` 使用 `tds_low` NTU
- [ ] `0x08`/`0x09` 可分别控制 USB 灯与雾化器
- [ ] 水泵 `0x01`、`0x04`~`0x07` 行为与 §3.2 一致
- [ ] 土壤 `0x02` 行为与旧版一致
