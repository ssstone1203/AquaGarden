# AquaGarden RA8P1 串口命令表

> **文档性质**：面向上位机/调试人员的 **API 参考手册**（可直接按 HEX 发命令）  
> **协议规范**：字节布局与语义以 [`通信协议.md`](通信协议.md) v1 为准；本文侧重「怎么用」  
> **固件版本**：`hardware/ra8p1/aquagarden/` 当前实现（单任务 `main_service`）  
> **最后更新**：2026-06-24

---

## 1. 概述

RA8P1 作为 **UART 下位机**，与上位机采用 **半双工、无应答** 模型：

| 方向 | 同步头 | 用途 | 周期 |
|------|--------|------|------|
| **下行**（Host → MCU） | `5A A5` | 控制外设、修改配置 | 按需发送 |
| **上行**（MCU → Host） | `55 AA` | 传感器快照 + 执行器状态 + 告警 | **250 ms** 自动上报 |

**重要**：下行命令 **没有即时 ACK**。发送后请监听上行帧，通过对应字段确认是否生效（见 §6）。

### 1.1 物理层

| 项目 | 值 |
|------|-----|
| 接口 | UART（SCI4 `g_uart0`） |
| 引脚 | TX=`P714`，RX=`P715`（与上位机交叉、共地） |
| 波特率 | **115200** |
| 数据位 | 8 |
| 校验 | 无（N） |
| 停止位 | 1 |
| 流控 | 无 |

### 1.2 通用帧格式（下行）

```
偏移  长度  字段       说明
0     1     SYNC0      固定 0x5A
1     1     SYNC1      固定 0xA5
2     1     LEN        = 1 + payload 字节数（含 CMD 本身 1 字节）
3     1     CMD        命令码（见 §2 索引）
4     N     PAYLOAD    参数（可为空）
4+N   2     CRC16      Modbus CRC16，**低字节在前**
```

**CRC16 算法**：多项式 `0xA001`，初值 `0xFFFF`；计算范围从 `SYNC0` 到 payload 末字节（**含 SYNC，不含 CRC**）。

**字节序**：多字节整数默认 **小端（LE）**；温度阈值用 **int16 LE，物理值 ×10**。

### 1.3 固件默认配置（上电）

| 参数 | 默认值 |
|------|--------|
| 水泵模式 | 自动联动 |
| 水泵自动 PWM | 60% |
| 土壤湿度阈值 | 30% |
| 土壤回差 | 10% |
| 联动 enable_bits | `0x07`（土壤 + 水温 + TDS 均启用） |
| 水温联动上限 | 30.0 ℃ |
| TDS 联动下限 | 300 NTU |
| 雾化器 | 关 |
| USB 灯模式 | `0xFF`（未设置/未就绪） |

## 2. 命令索引

| CMD | 名称 | 外设/功能 | Payload 长度 | 推荐度 |
|-----|------|-----------|--------------|--------|
| `0x01` | Set Manual Pump | 水泵 | 2 | 遗留，可用 |
| `0x02` | Soil Config | 联动配置（土壤） | 2 | 常用 |
| `0x03` | Linkage Config | 联动配置（水温/TDS/使能） | 5 | 常用 |
| `0x04` | Pump Start | 水泵 | 0 或 1 | **推荐** |
| `0x05` | Pump Stop | 水泵 | 0 | **推荐** |
| `0x06` | Set Pump PWM | 水泵 | 1 | **推荐** |
| `0x07` | Set Pump Auto | 水泵 | 0 | **推荐** |
| `0x08` | USB Light Set Mode | USB 报警灯 | 1 | 常用 |
| `0x09` | Atomizer Set | 雾化器 | 1 | 常用 |

未知 CMD：固件 **静默忽略**（不置 `COMM_RX_ERROR`）。

## 3. 水泵 API

水泵通过 DRV8870 驱动，PWM 范围 **0..100%**。存在 **自动联动** 与 **手动** 两种模式：

- **自动**：根据传感器融合结果控制 PWM（联动需浇水 → 60%，否则 0%）。
- **手动**：由 `0x01`/`0x04`~`0x06` 指定 PWM；`0x07` 恢复自动。

### 3.1 `0x04` Pump Start — 启动水泵（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x04` |
| Payload | 空，或 `[pwm_percent]` |
| LEN | `0x01`（无 payload）或 `0x02`（带 PWM） |

**行为**：

1. 切入 **手动模式**。
2. 若带 `pwm_percent`，设为该值（>100 钳为 100）。
3. 若不带 payload，或当前手动 PWM 为 0，则设为 **60%**。

| 场景 | 完整 HEX |
|------|----------|
| 启动（默认 60%） | `5A A5 01 04 02 8C` |
| 启动并设 80% | `5A A5 02 04 50 FD FD` |

**确认**：上行 payload[13] `pump_pwm` 应变为目标值；手动模式下联动不再改 PWM。

---

### 3.2 `0x05` Pump Stop — 停止水泵（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x05` |
| Payload | 无 |
| LEN | `0x01` |

**行为**：手动模式，PWM 置 **0%**。

| 完整 HEX |
|----------|
| `5A A5 01 05 C3 4C` |

---

### 3.3 `0x06` Set Pump PWM — 设置水泵速度（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x06` |
| Payload | `[pwm_percent]`，`0..100` |
| LEN | `0x02` |

**行为**：切入手动模式并设置 PWM。Payload 长度不足时 **忽略**。

| 场景 | 完整 HEX |
|------|----------|
| 设为 50% | `5A A5 02 06 32 7D 74` |
| 设为 100% | `5A A5 02 06 64 3C 75` |

---

### 3.4 `0x07` Set Pump Auto — 恢复自动联动

| 字段 | 值 |
|------|-----|
| CMD | `0x07` |
| Payload | 无 |
| LEN | `0x01` |

**行为**：退出手动，恢复传感器联动逻辑。

| 完整 HEX |
|----------|
| `5A A5 01 07 42 8D` |

---

### 3.5 `0x01` Set Manual Pump — 遗留接口

| 字段 | 值 |
|------|-----|
| CMD | `0x01` |
| Payload | `[manual_mode, pwm_percent]` |
| LEN | `0x03` |

| manual_mode | 含义 |
|-------------|------|
| `0` | 自动联动 |
| `1` | 手动；`pwm>0` 运行，`pwm=0` 停止 |

Payload 长度 < 2 时 **忽略**。

| 场景 | 完整 HEX |
|------|----------|
| 手动运行 75% | `5A A5 03 01 01 4B 50 DB` |
| 恢复自动 | `5A A5 03 01 00 00 11 7C` |
| 手动停止 | `5A A5 03 01 01 00 91 1B` |

> 新开发请优先使用 `0x04`~`0x07`。

## 4. 联动配置 API

联动配置不直接驱动外设，但影响 **自动模式下水泵** 的行为及 **alarm_flags** 告警位。

### 4.1 `0x02` Soil Config — 土壤湿度阈值

| 字段 | 值 |
|------|-----|
| CMD | `0x02` |
| Payload | `[threshold, hysteresis]` |
| LEN | `0x03` |

| 参数 | 单位 | 范围 | 说明 |
|------|------|------|------|
| threshold | % | 0..100 | 低于此值触发「需浇水」 |
| hysteresis | % | 0..100 | 回差，防止阈值附近抖动 |

**行为**：土壤湿度 **低于** `threshold - hysteresis` 时置 `need_watering=1`；高于 `threshold` 时清除。

| 场景 | 完整 HEX |
|------|----------|
| 阈值 30%，回差 10%（默认） | `5A A5 03 02 1E 0A 68 DB` |
| 阈值 40%，回差 5% | `5A A5 03 02 28 05 A9 1A` |

---

### 4.2 `0x03` Linkage Config — 联动总配置

| 字段 | 值 |
|------|-----|
| CMD | `0x03` |
| Payload | `[enable_bits, temp_high_lo, temp_high_hi, tds_low_lo, tds_low_hi]` |
| LEN | `0x06` |

**enable_bits**：

| Bit | 含义 |
|-----|------|
| 0 | 启用土壤湿度联动 |
| 1 | 启用水温过高联动 |
| 2 | 启用 TDS 过低联动 |
| 3–7 | 保留，填 0 |

**temp_high**：int16 LE，物理值 = 寄存器值 / 10（℃），固件钳位 **0.0..100.0 ℃**。

**tds_low**：uint16 LE，单位 **NTU**（浊度）。

Payload 长度 < 5 时 **忽略**。

| 场景 | Payload（hex） | 完整 HEX |
|------|----------------|----------|
| 全开；水温上限 28.0℃；TDS 下限 300 NTU | `07 18 01 2C 01` | `5A A5 06 03 07 18 01 2C 01 1B 87` |
| 仅土壤联动；水温上限 25.0℃ | `01 FA 00 00 00` | `5A A5 06 03 01 FA 00 00 00 29 3F` |
| 关闭全部联动 | `00 00 00 00 00` | `5A A5 06 03 00 00 00 00 00 24 27` |
| 默认等效（28℃/300 NTU，全开） | `07 1E 01 2C 01` | `5A A5 06 03 07 1E 01 2C 01 5A 46` |

**告警关联**（见 §6.3）：水温超阈值 → bit5；TDS 低于下限 → bit6。

## 5. 执行器 API

### 5.1 `0x09` Atomizer Set — 雾化器开关

| 字段 | 值 |
|------|-----|
| CMD | `0x09` |
| Payload | `[state]` |
| LEN | `0x02` |
| 硬件 | GPIO `P402`，高电平=开 |

| state | 含义 |
|-------|------|
| `0` | 关 |
| `1` | 开 |
| 其他 | **忽略**，不改变状态 |

| 场景 | 完整 HEX |
|------|----------|
| 开启 | `5A A5 02 09 01 38 91` |
| 关闭 | `5A A5 02 09 00 F9 51` |

**确认**：上行 payload[15] `atomizer_state` 变为 0/1。

---

### 5.2 `0x08` USB Light Set Mode — USB 报警灯

| 字段 | 值 |
|------|-----|
| CMD | `0x08` |
| Payload | `[mode]` |
| LEN | `0x02` |
| 硬件 | USB HS Host + CH340 转串口 Modbus 帧 |

**前置条件**：

1. 报警灯已插入 RA8P1 **USB HS** 口（非调试 FS 口）。
2. CH340 枚举完成（上电后约 **1 s**）；未完成时命令返回失败，上行 `usb_light_mode` 不变。
3. 上行 `alarm_flags` bit9（`USB_LIGHT_FAULT`）为 0 表示 USB 灯链路正常。

**mode 范围**：`0..26`；超出范围时固件 **拒绝**，不更新 `usb_light_mode`。

## 6. 上行状态帧（Telemetry API）

MCU 每 **250 ms** 主动发送 **38 字节** 上行帧。上位机通过解析此帧确认命令效果并读取传感器。

### 6.1 帧格式

```
偏移  长度  字段           值
0     1     SYNC0          0x55
1     1     SYNC1          0xAA
2     1     VER            0x02（必须检查）
3     1     SEQ            序号（uint8 回绕）
4     2     PAYLOAD_LEN    0x1E 0x00（固定 30）
6     30    PAYLOAD        见下表
36    2     CRC16          Modbus，低字节在前
```

### 6.2 PAYLOAD 字段（30 字节）

| 偏移 | 长 | 字段 | 类型 | 物理含义 | 命令确认用途 |
|------|-----|------|------|----------|--------------|
| 0 | 4 | timestamp_ms | u32 LE | 系统运行毫秒 | — |
| 4 | 2 | air_temp | i16 LE | 气温 ℃ ×10 | — |
| 6 | 2 | air_humi | i16 LE | 空气湿度 % ×10 | — |
| 8 | 2 | water_temp | i16 LE | 水温 ℃ ×10 | — |
| 10 | 1 | soil_moisture | u8 | 土壤湿度 0..100 % | — |
| 11 | 2 | tds_ntu | u16 LE | TDS/浊度 NTU | — |
| 13 | 1 | pump_pwm | u8 | 水泵 PWM 0..100 | 确认 0x01/0x04~0x06 |
| 14 | 1 | need_watering | u8 | 联动需浇水 0/1 | 确认联动逻辑 |
| 15 | 1 | atomizer_state | u8 | 雾化器 0/1 | 确认 0x09 |
| 16 | 1 | usb_light_mode | u8 | 灯模式 0..26 或 0xFF | 确认 0x08 |
| 17 | 3 | reserved | — | 填 0 | — |
| 20 | 4 | alarm_flags | u32 LE | 告警位图 | 见 §6.3 |
| 24 | 2 | air_retry_count | u16 LE | 温湿度失败计数 | — |
| 26 | 2 | tds_retry_count | u16 LE | TDS 失败计数 | — |
| 28 | 2 | uwt_retry_count | u16 LE | 水温失败计数 | — |

**解码示例**（节选）：

```
55 AA 02 46 1E 00 7C 46 00 00 04 01 8F 03 32 01 64 00 00 3C 01 00 FF ...
                              ^^^^^^^^ ^^ ^^ ^^ ^^
                              ts=18044  26.0℃ 91.1% 30.6℃  soil=100
                                                    tds=0 pump=60 need=1
                                                              atom=0 light=0xFF
```

### 6.3 alarm_flags 位定义

| Bit | 名称 | 触发条件 |
|-----|------|----------|
| 0 | SOIL_SENSOR_FAULT | 土壤 ADC 读取失败 |
| 2 | AIR_READ_FAIL | 温湿度累计失败（`air_retry_count > 0`） |
| 3 | TDS_READ_FAIL | TDS 累计失败 |
| 4 | UWT_READ_FAIL | 水温累计失败 |
| 5 | WATER_TEMP_HIGH | 水温超过联动上限 |
| 6 | TDS_LOW | TDS 低于联动下限 |
| 8 | COMM_RX_ERROR | 下行帧 CRC/格式错误（累计后 latch） |
| 9 | USB_LIGHT_FAULT | USB 灯链路异常或未就绪 |
| 10 | ATOMIZER_FAULT | 保留（当前固件未置位） |

## 7. 错误与边界行为

| 情况 | 固件行为 |
|------|----------|
| SYNC 不是 `5A A5` | 帧丢弃 |
| CRC 错误 / 长度不匹配 | 丢弃；`COMM_RX_ERROR` 累计 |
| 未知 CMD | 静默忽略 |
| Payload 长度不足 | 该 CMD **不执行**（如 `0x06` 无 payload） |
| PWM / 阈值 > 100 | 钳位为 100 |
| USB 灯 mode > 26 | 拒绝，保持原模式 |
| 雾化器 state > 1 | 忽略 |
| 下行无应答 | 正常；请读上行帧 |

## 8. 典型操作流程

### 8.1 串口助手手动调试

1. 打开串口 **115200 8N1**，HEX 显示 + HEX 发送。
2. 确认持续收到 `55 AA 02 ...` 上行帧（38 字节）。
3. 发送下行 HEX（**不要**附加换行）。
4. 等待下一帧上行，检查对应状态字段。

### 8.2 开机自检序列（建议）

| 步骤 | 发送 | 期望上行变化 |
|------|------|--------------|
| 1 | （仅监听） | 持续 250 ms 周期 `55 AA` |
| 2 | `5A A5 02 09 01 38 91` | atomizer_state → 1 |
| 3 | `5A A5 02 08 02 79 00` | usb_light_mode → 2（需 USB 灯就绪） |
| 4 | `5A A5 01 04 02 8C` | pump_pwm → 60 |
| 5 | `5A A5 01 05 C3 4C` | pump_pwm → 0 |
| 6 | `5A A5 01 07 42 8D` | 恢复自动，pump_pwm 随联动变化 |
| 7 | `5A A5 02 09 00 F9 51` | atomizer_state → 0 |
| 8 | `5A A5 02 08 1A 79 0A` | usb_light_mode → 26 |

## 9. 不在串口协议内的外设

以下模块 **仅通过上行帧上报**，**无**独立下行 CMD：

| 模块 | 上报字段 | 说明 |
|------|----------|------|
| DS18B20 水温 | water_temp, uwt_retry_count | 非阻塞采样 |
| SHT30 温湿度 | air_temp, air_humi, air_retry_count | 约 1 s/次 |
| 土壤湿度 ADC | soil_moisture | 约 40 ms/次 |
| TDS ADC | tds_ntu, tds_retry_count | 约 40 ms/次；NTU 由电压曲线换算 |
