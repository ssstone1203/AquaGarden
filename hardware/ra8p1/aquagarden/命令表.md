# AquaGarden 命令表（应用层 API）

> **文档性质**：面向上位机/调试人员的 **API 参考手册**（可直接按 HEX 发命令）  
> **协议规范**：字节布局与语义以 [`通信协议.md`](通信协议.md) v1 为准（**规范权威来源**）；本文侧重「怎么用」  
> **阅读路径**：发命令/联调 → 本文；规范细节 → [`通信协议.md`](通信协议.md)；固件/RASC → [`工程说明.md`](工程说明.md)；接线 → [`接线指南.md`](接线指南.md)  
> **固件版本**：`hardware/ra8p1/aquagarden/`（单任务 `main_service`）  
> **传输绑定**：当前默认 UART；§1.5 引脚/波特率，§1.6 SPI/I2C 复用

## 1. 概述

本文定义 **AquaGarden 应用层协议 v1**（下称「应用协议」）：CMD、Payload、上行 Telemetry 字段及语义 **与底层物理总线无关**。同一套命令字节可承载在 UART、SPI、I2C 等传输之上，只需替换传输适配层（固件中对应 `com_service.*`）。

当前 RA8P1 工程 **默认绑定 UART**（§1.5）；下文 HEX 示例均为 **完整应用层帧**，可直接用于串口调试，也可原样嵌入其他总线事务。

### 1.1 协议分层

```
┌──────────────────────────────────────────────┐
│  应用层（本文 + 通信协议.md）                  │
│  CMD 0x01~0x09、上行 30B Payload、alarm 语义   │  ← 可跨总线复用
├──────────────────────────────────────────────┤
│  帧格式层                                     │
│  下行 5A A5 … CRC16  /  上行 55 AA … CRC16    │  ← 可跨总线复用
├──────────────────────────────────────────────┤
│  传输层（总线相关）                            │
│  UART / SPI / I2C … 定界、时序、引脚           │  ← 按硬件替换
└──────────────────────────────────────────────┘
```

固件中 **`com_protocol.*` 属于应用层**（编解码 + 调业务）；**`com_service.*` 属于传输层**（UART 收发与定界）。迁移总线时通常 **只改传输层**。

### 1.2 应用层交互模型

| 方向 | 同步头 | 用途 | 典型时机 |
|------|--------|------|----------|
| **下行**（Host → MCU） | `5A A5` | 控制外设、修改配置 | 按需发送 |
| **上行**（MCU → Host） | `55 AA` | 传感器快照 + 执行器状态 + 告警 | 周期性或主机轮询读取 |

**重要**：

- 应用层 **无下行 ACK**；发送后读上行帧，通过对应字段确认是否生效（见 §6）。
- **「250 ms 主动上行」** 是当前 **UART 绑定** 的实现策略（§1.5），不是应用层硬性要求；SPI/I2C 可改为主机轮询读状态（§1.6）。

### 1.3 下行帧格式（摘要）

下行帧：`5A A5` + `LEN` + `CMD` + `PAYLOAD` + CRC16（Modbus，低字节在前）。

完整偏移表、CRC 算法与字节序见 [`通信协议.md`](通信协议.md) §2、§3.1。

### 1.4 固件默认配置（上电）

| 参数 | 默认值 |
|------|--------|
| 水泵模式 | 自动联动 |
| 水泵自动 PWM | 60% |
| 土壤湿度阈值 | 30% |
| 土壤回差 | 10% |
| 联动 enable_bits | `0x07`（土壤 + 水温 + TDS 均启用） |
| 水温联动上限 | 30.0 ℃ |
| TDS 联动下限 | 300 NTU |
| 雾化器 | 关 |
| USB 灯模式 | `0xFF`（未设置/未就绪） |

### 1.5 UART 传输绑定（当前实现）

以下为 `hardware/ra8p1/aquagarden/` **当前工程** 的传输层参数；换用 SPI/I2C 时 **不必修改** §2~§6 的应用语义。

**物理层**

| 项目 | 值 |
|------|-----|
| 接口 | UART（SCI4 `g_uart0`） |
| 引脚 | TX=`P714`，RX=`P715`（与上位机交叉、共地） |
| 波特率 | **115200** |
| 数据位 | 8 |
| 校验 | 无（N） |
| 停止位 | 1 |
| 流控 | 无 |

**传输层行为**

| 项目 | 行为 |
|------|------|
| 下行定界 | RX 逐字节状态机：识别 `5A A5` + LEN，整帧 CRC 校验 |
| 上行发送 | MCU 每 **250 ms** 主动发送 38 字节（寄存器轮询 TX） |
| 双工 | 半双工；ISR 仅收 RX，不在中断里调 FreeRTOS API |

### 1.6 可移植性与其他总线映射

**可直接复用（换总线也不改）**

| 内容 |
|------|
| CMD `0x01`~`0x09` 及 Payload 布局 |
| 上行 30 字节 Payload 与 `alarm_flags` 定义 |
| CRC16 Modbus 算法与字节序约定 |
| `com_protocol.c` 中的 `com_downlink_decode` / `com_apply_downlink` / `com_build_uplink` |

**随总线需调整**

| 内容 | 说明 |
|------|------|
| 传输适配（`com_service.*`） | 字节读写、帧定界、错误上报 |
| 上行推送 vs 主机轮询 | UART 现为主动推送；SPI/I2C 通常改为主机读「状态块」 |
| SYNC 字节必要性 | 字节流（UART）强烈依赖；I2C 寄存器映射可选保留（便于与 UART 版统一） |

**常见映射方案**

| 方案 | 下行（Host → MCU） | 上行（MCU → Host） | 说明 |
|------|-------------------|-------------------|------|
| **A. 原样字节流** | 写完整帧 `5A A5 LEN CMD … CRC` | 读 38 字节 `55 AA VER … CRC` | 与本文 HEX **完全一致**；推荐 SPI 全双工或 I2C 块读写 |
| **B. 寄存器映射** | 写命令寄存器区 `0x00..`（内容同左） | 读状态寄存器区 `0x40..`（38 B） | 语义相同，文档表述为寄存器地址 |
| **C. 请求-响应** | 一帧下行随 SPI 事务发出 | 同一事务或下一事务返回上行 | 可省 SYNC 定界，但 CMD 语义不变 |

> 应用层最大帧：下行 ≤ 13 字节（2 SYNC + LEN + CMD + 8 payload + 2 CRC），上行固定 38 字节，对 SPI/I2C 缓冲区压力很小。

## 3. 水泵 API

水泵通过 DRV8870 驱动，PWM 范围 **0..100%**。存在 **自动联动** 与 **手动** 两种模式：

- **自动**：根据传感器融合结果控制 PWM（联动需浇水 → 60%，否则 0%）。
- **手动**：由 `0x01`/`0x04`~`0x06` 指定 PWM；`0x07` 恢复自动。

### 3.1 `0x04` Pump Start — 启动水泵（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x04` |
| Payload | 空，或 `[pwm_percent]` |
| LEN | `0x01`（无 payload）或 `0x02`（带 PWM） |

**行为**：

1. 切入 **手动模式**。
2. 若带 `pwm_percent`，设为该值（>100 钳为 100）。
3. 若不带 payload，或当前手动 PWM 为 0，则设为 **60%**。

| 场景 | 完整 HEX |
|------|----------|
| 启动（默认 60%） | `5A A5 01 04 02 8C` |
| 启动并设 80% | `5A A5 02 04 50 FD FD` |

**确认**：上行 payload[13] `pump_pwm` 应变为目标值；手动模式下联动不再改 PWM。

---

### 3.2 `0x05` Pump Stop — 停止水泵（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x05` |
| Payload | 无 |
| LEN | `0x01` |

**行为**：手动模式，PWM 置 **0%**。

| 完整 HEX |
|----------|
| `5A A5 01 05 C3 4C` |

---

### 3.3 `0x06` Set Pump PWM — 设置水泵速度（手动）

| 字段 | 值 |
|------|-----|
| CMD | `0x06` |
| Payload | `[pwm_percent]`，`0..100` |
| LEN | `0x02` |

**行为**：切入手动模式并设置 PWM。Payload 长度不足时 **忽略**。

| 场景 | 完整 HEX |
|------|----------|
| 设为 50% | `5A A5 02 06 32 7D 74` |
| 设为 100% | `5A A5 02 06 64 3C 75` |

---

### 3.4 `0x07` Set Pump Auto — 恢复自动联动

| 字段 | 值 |
|------|-----|
| CMD | `0x07` |
| Payload | 无 |
| LEN | `0x01` |

**行为**：退出手动，恢复传感器联动逻辑。

| 完整 HEX |
|----------|
| `5A A5 01 07 42 8D` |

---

### 3.5 `0x01` Set Manual Pump — 遗留接口

| 字段 | 值 |
|------|-----|
| CMD | `0x01` |
| Payload | `[manual_mode, pwm_percent]` |
| LEN | `0x03` |

| manual_mode | 含义 |
|-------------|------|
| `0` | 自动联动 |
| `1` | 手动；`pwm>0` 运行，`pwm=0` 停止 |

Payload 长度 < 2 时 **忽略**。

| 场景 | 完整 HEX |
|------|----------|
| 手动运行 75% | `5A A5 03 01 01 4B 50 DB` |
| 恢复自动 | `5A A5 03 01 00 00 11 7C` |
| 手动停止 | `5A A5 03 01 01 00 91 1B` |

> 新开发请优先使用 `0x04`~`0x07`。

## 4. 联动配置 API

联动配置不直接驱动外设，但影响 **自动模式下水泵** 的行为及 **alarm_flags** 告警位。

### 4.1 `0x02` Soil Config — 土壤湿度阈值

| 字段 | 值 |
|------|-----|
| CMD | `0x02` |
| Payload | `[threshold, hysteresis]` |
| LEN | `0x03` |

| 参数 | 单位 | 范围 | 说明 |
|------|------|------|------|
| threshold | % | 0..100 | 触发「需浇水」的上限参考值 |
| hysteresis | % | 0..100 | 回差，防止阈值附近抖动 |

**行为**（与 [`通信协议.md`](通信协议.md) §3.3 `0x02` 一致）：

- 土壤湿度 **≤ threshold** → `need_watering=1`
- 土壤湿度 **≥ threshold + hysteresis** → `need_watering=0`
- 介于两者之间 → 保持上一周期决策

| 场景 | 完整 HEX |
|------|----------|
| 阈值 30%，回差 10%（默认） | `5A A5 03 02 1E 0A 68 DB` |
| 阈值 40%，回差 5% | `5A A5 03 02 28 05 A9 1A` |

---

### 4.2 `0x03` Linkage Config — 联动总配置

| 字段 | 值 |
|------|-----|
| CMD | `0x03` |
| Payload | `[enable_bits, temp_high_lo, temp_high_hi, tds_low_lo, tds_low_hi]` |
| LEN | `0x06` |

**enable_bits**：

| Bit | 含义 |
|-----|------|
| 0 | 启用土壤湿度联动 |
| 1 | 启用水温过高联动 |
| 2 | 启用 TDS 过低联动 |
| 3–7 | 保留，填 0 |

**temp_high**：int16 LE，物理值 = 寄存器值 / 10（℃），固件钳位 **0.0..100.0 ℃**。

**tds_low**：uint16 LE，单位 **NTU**（浊度）。

Payload 长度 < 5 时 **忽略**。

| 场景 | Payload（hex） | 完整 HEX |
|------|----------------|----------|
| 全开；水温上限 28.0℃；TDS 下限 300 NTU | `07 18 01 2C 01` | `5A A5 06 03 07 18 01 2C 01 1B 87` |
| 仅土壤联动；水温上限 25.0℃ | `01 FA 00 00 00` | `5A A5 06 03 01 FA 00 00 00 29 3F` |
| 关闭全部联动 | `00 00 00 00 00` | `5A A5 06 03 00 00 00 00 00 24 27` |
| 默认等效（28℃/300 NTU，全开） | `07 1E 01 2C 01` | `5A A5 06 03 07 1E 01 2C 01 5A 46` |

**告警关联**（见 [`通信协议.md`](通信协议.md) §4.3）：水温超阈值 → bit5；TDS 低于下限 → bit6。

## 5. 执行器 API

### 5.1 `0x09` Atomizer Set — 雾化器开关

| 字段 | 值 |
|------|-----|
| CMD | `0x09` |
| Payload | `[state]` |
| LEN | `0x02` |
| 硬件 | GPIO `P402`，高电平=开 |

| state | 含义 |
|-------|------|
| `0` | 关 |
| `1` | 开 |
| 其他 | **忽略**，不改变状态 |

| 场景 | 完整 HEX |
|------|----------|
| 开启 | `5A A5 02 09 01 38 91` |
| 关闭 | `5A A5 02 09 00 F9 51` |

**确认**：上行 payload[15] `atomizer_state` 变为 0/1。

---

### 5.2 `0x08` USB Light Set Mode — USB 报警灯

| 字段 | 值 |
|------|-----|
| CMD | `0x08` |
| Payload | `[mode]` |
| LEN | `0x02` |
| 硬件 | USB HS Host + CH340 转串口 Modbus 帧 |

**前置条件**：

1. 报警灯已插入 RA8P1 **USB HS** 口（非调试 FS 口）。
2. CH340 枚举完成（上电后约 **1 s**）；未完成时命令返回失败，上行 `usb_light_mode` 不变。
3. 上行 `alarm_flags` bit9（`USB_LIGHT_FAULT`）为 0 表示 USB 灯链路正常。

**mode 范围**：`0..26`；超出范围时固件 **拒绝**，不更新 `usb_light_mode`。

## 6. 上行状态帧（Telemetry API）

应用层上行帧固定 **38 字节**（30 字节 Payload + 帧头/CRC）。完整字段类型、alarm 位定义见 [`通信协议.md`](通信协议.md) §4。

> **UART 绑定**：当前固件每 **250 ms** 主动发送一帧。其他总线可改为主机轮询读同一 38 字节块。

### 6.1 帧格式（摘要）

`55 AA` + `VER=0x02` + `SEQ` + `PAYLOAD_LEN=30` + Payload + CRC16。详见 [`通信协议.md`](通信协议.md) §4.1。

### 6.2 PAYLOAD 字段索引（联调速查）

| Payload 偏移 | 字段 | 命令确认用途 |
|-------------|------|--------------|
| 13 | `pump_pwm` | 确认 0x01 / 0x04~0x06 |
| 14 | `need_watering` | 确认联动逻辑 |
| 15 | `atomizer_state` | 确认 0x09 |
| 16 | `usb_light_mode` | 确认 0x08（未就绪 `0xFF`） |
| 20 | `alarm_flags` | 见 [`通信协议.md`](通信协议.md) §4.3 |

其余传感器字段（温湿度、水温、土壤、TDS、retry 计数等）见 [`通信协议.md`](通信协议.md) §4.2。

### 6.3 解码示例

```
55 AA 02 46 1E 00 7C 46 00 00 04 01 8F 03 32 01 64 00 00 3C 01 00 FF ...
                              ^^^^^^^^ ^^ ^^ ^^ ^^
                              ts=18044  26.0℃ 91.1% 30.6℃  soil=100
                                                    tds=0 pump=60 need=1
                                                              atom=0 light=0xFF
```

## 7. 错误与边界行为

| 情况 | 固件行为 |
|------|----------|
| SYNC 不是 `5A A5` | 帧丢弃 |
| CRC 错误 / 长度不匹配 | 丢弃；`COMM_RX_ERROR` 累计 |
| 未知 CMD | 静默忽略 |
| Payload 长度不足 | 该 CMD **不执行**（如 `0x06` 无 payload） |
| PWM / 阈值 > 100 | 钳位为 100 |
| USB 灯 mode > 26 | 静默拒绝，不更新模式，不置 `COMM_RX_ERROR`（见 [`通信协议.md`](通信协议.md) §3.4） |
| 雾化器 state > 1 | 忽略 |
| 下行无应答 | 正常；请读上行帧 |

## 8. 典型操作流程

### 8.1 UART：串口助手手动调试

1. 打开串口 **115200 8N1**，HEX 显示 + HEX 发送。
2. 确认持续收到 `55 AA 02 ...` 上行帧（38 字节）。
3. 发送下行 HEX（**不要**附加换行）。
4. 等待下一帧上行，检查对应状态字段。

### 8.2 开机自检序列（建议）

| 步骤 | 发送 | 期望上行变化 |
|------|------|--------------|
| 1 | （仅监听） | 持续 250 ms 周期 `55 AA` |
| 2 | `5A A5 02 09 01 38 91` | atomizer_state → 1 |
| 3 | `5A A5 02 08 02 79 00` | usb_light_mode → 2（需 USB 灯就绪） |
| 4 | `5A A5 01 04 02 8C` | pump_pwm → 60 |
| 5 | `5A A5 01 05 C3 4C` | pump_pwm → 0 |
| 6 | `5A A5 01 07 42 8D` | 恢复自动，pump_pwm 随联动变化 |
| 7 | `5A A5 02 09 00 F9 51` | atomizer_state → 0 |
| 8 | `5A A5 02 08 1A 79 0A` | usb_light_mode → 26 |

## 9. 无下行 CMD 的外设（只读 Telemetry）

以下模块 **仅通过上行 Payload 上报**，应用层 **无** 独立下行 CMD：

| 模块 | 上报字段 | 说明 |
|------|----------|------|
| DS18B20 水温 | water_temp, uwt_retry_count | 非阻塞采样 |
| SHT30 温湿度 | air_temp, air_humi, air_retry_count | 约 1 s/次 |
| 土壤湿度 ADC | soil_moisture | 约 40 ms/次 |
| TDS ADC | tds_ntu, tds_retry_count | 约 40 ms/次；NTU 由电压曲线换算 |
