# AquaGarden RA8P1 接线指南

> **职责**：硬件接线、引脚分配、模块↔外设对应关系。  
> **阅读路径**：硬件接线 → 本文；协议规范 → [`通信协议.md`](通信协议.md)；发命令/联调 → [`命令表.md`](命令表.md)；改固件 → [`工程说明.md`](工程说明.md)  
> **范围**：`hardware/ra8p1/aquagarden/`  
> **约束**：不含压力传感器、WQM/UART 水质模块；TDS 走 ADC；通信下行只接受 `5A A5`。

| 空气温湿度 SHT30 | 传感器  | **3.3 V**     | `device/dev_sht30_driver.*`                      | `hardware/demo/th_sensor/`、`data_merge/src/sht30.*`    | I2C 7-bit 地址 `0x44`（模块可 3.3/5 V，本工程接 3.3 V） |

### 1.1 供电汇总（接线时对照）

| 电源轨       | 接哪些模块                              | 说明                                             |
| --------- | ---------------------------------- | ---------------------------------------------- |
| **3.3 V** | DS18B20、SHT30、雾化器；MCU IO / UART 逻辑 | 与 RA8P1 `VCC=3.3 V` 一致；传感器信号线勿直接灌入更高电平         |
| **5 V**   | 土壤湿度、TDS；USB 报警灯经 Host **VBUS**    | 土壤 / TDS 的 AO 接 ADC 前须分压或限幅，不超过 RA8P1 ADC 允许电压 |
| **12 V**  | 水泵（经 DRV8870 **VM**）               | 仅给泵功率端；驱动逻辑脚 IN1/`P104`、PWM/`P105` 仍为 3.3 V    |
| **共地**    | 所有电源与 RA8P1 **GND 必须共地**           | 12 V / 5 V / 3.3 V 负极与板地相连                     |

## 4. TDS 接线与换算

| TDS 传感器 | MCU / 电源                                |
| ------- | --------------------------------------- |
| `+`     | **5 V** 供电；AO 经分压/限幅，不超过 RA8P1 ADC 允许电压 |
| `-`     | GND，与 RA8P1 共地                          |
| `A`     | `ADC0_AN002` / `P002`                   |

固件换算使用标准曲线（**本文为硬件侧权威说明**）：

```text
y = 66.71x^3 - 127.93x^2 + 428.7x
x = ADC 电压（V），范围 0–3 V
y = NTU（u16 LE，上行字段 tds_ntu）
```

固件实现：5 点中值滤波；**不做** Arduino ppm 温度补偿。详见 [`工程说明.md`](工程说明.md) §TDS。

## 5. 任务与服务（摘要）

单一 10 ms 任务 `main_service`；UART/USB 均并入，无第二常驻任务。任务模型与初始化顺序见 [`工程说明.md`](工程说明.md) §「任务模型」。

| 服务                           | 职责                                                                            | 周期    |
| ---------------------------- | ----------------------------------------------------------------------------- | ----- |
| `aqua_app_process_10ms()`    | 传感器状态机、融合、执行器、USB bringup、snapshot/alarm                                      | 10 ms |
| `com_service_process_10ms()` | 解析 `5A A5` 下行 → `com_apply_downlink()`；每 250 ms 组 `55 AA` 上行并 **TX 寄存器轮询** 发送 | 10 ms |

- 下行解析在任务上下文；RX 经 `UART_EVENT_RX_CHAR` ISR 入帧缓冲，ISR **不调用 FreeRTOS API**。
- CMD 与 `aqua_app_*` 映射、完整 HEX 见 [`命令表.md`](命令表.md)。

协议字节布局、CMD 语义、上行 Payload 以 [`通信协议.md`](通信协议.md) 为规范；可直接复制的 HEX 命令与联调步骤见 [`命令表.md`](命令表.md) §8。

## 7. 初始化顺序

1. `g_common_init()` / RASC 外设初始化。
2. `main_service_entry()` → `aqua_app_init()`（全部 device）→ `com_service_init()`（UART）。
3. 10 ms 循环：`aqua_app_process_10ms()` → `com_service_process_10ms()` → `vTaskDelay(10ms)`。

上电默认参数（水泵自动、阈值、联动等）见 [`命令表.md`](命令表.md) §1.4。

## 8. 已确认结论

1. **单一任务 `main_service`**；原 `com`、`new_thread0` 已删除。
2. 土壤 / TDS ADC：`P001` / `P002`；TDS AO 已分压/限幅。
3. USB HS：`P407`/`P408`；RTOS 下 `R_USB_Open` 须注册非空 `p_usb_apl_callback`，控制传输用任务通知；**禁止**裸机 `R_USB_EventGet` 轮询（会崩进 `Default_Handler`）。详见 [`工程说明.md`](工程说明.md) §设备注意事项。
4. UART：**TX 寄存器轮询**（`com_uart_write_polling`）；**RX char 回调**入帧状态机。不用 FSP 中断式 `write()`（见 `DEBUG_RECORD.md`）。
