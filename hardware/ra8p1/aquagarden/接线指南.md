# AquaGarden RA8P1 接线指南

> 状态：随单任务重写定稿；引脚按用户确认。  
> 范围：仅适用于 `hardware/ra8p1/aquagarden/` 目标工程。  
> 约束：不包含压力传感器，不使用 WQM/UART 水质模块；TDS 走 ADC，通信下行只接受 `5A A5`。

## 4. TDS 接线与换算

TDS 模块资料接线为：

| TDS 传感器 | MCU / 电源 |
|---|---|
| `+` | 传感器供电正，资料示例为 5 V；用户已确认 AO 经过分压/限幅，不超过 RA8P1 ADC 允许电压 |
| `-` | GND，必须与 RA8P1 共地 |
| `A` | ADC 输入，阶段 0 草案为 `ADC0_AN002/P002` |

固件阶段 1 换算只使用标准曲线：

```text
y = 66.71x^3 - 127.93x^2 + 428.7x
x = ADC 电压，范围 0-3 V
y = NTU，作为 u16 LE 放入上行 payload 的 tds_ntu
```

Arduino 例程只参考“40 ms 采样、30 点中值滤波”的流程，不使用其 ppm 与温度补偿公式。

## 5. 任务与服务接口设计

**单一 10ms 主服务任务 `main_service`**，UART 通信作为周期服务函数并入，不再拆分独立 `com` 任务：

| 服务 | 职责 | 周期 / 触发 |
|---|---|---|
| `aqua_app_process_10ms()` | 推进 DS18B20、SHT30、土壤 ADC、TDS ADC 非阻塞状态机；运行 `sensor_fusion` 联动；执行水泵控制；推进 USB 灯 bringup（事件经 FSP 回调异步送达）；维护 snapshot 与 alarm | 每 10 ms；各传感器内部自定速 |
| `com_service_process_10ms()` | 处理 `5A A5` 下行帧、调用控制接口；每 250 ms 组 `55 AA` 上行帧并经 FSP 中断式 `write()` 发送 | 每 10 ms；RX 经 ISR 回调入帧缓冲 |

控制/查询接口（均在同一任务内被 `com_service` 调用，无跨任务竞态，无需互斥量）：

| 接口 | 说明 |
|---|---|
| `aqua_app_get_snapshot(snapshot*)` | 复制 30 字节 payload 所需状态 |
| `aqua_app_set_pump_manual(mode, pwm)` | 对应 CMD `0x01` |
| `aqua_app_pump_start()` / `aqua_app_pump_stop()` / `aqua_app_set_pump_pwm()` / `aqua_app_set_pump_auto()` | 对应 CMD `0x04`-`0x07` |
| `aqua_app_set_soil_config(threshold, hysteresis)` | 对应 CMD `0x02` |
| `aqua_app_set_linkage(enable_bits, temp_high_x10, tds_low)` | 对应 CMD `0x03`，bit2 为 TDS 过低 |
| `aqua_app_set_usb_light_mode(mode)` | 对应 CMD `0x08`，范围 `0..26` |
| `aqua_app_set_atomizer(state)` | 对应 CMD `0x09`，`0/1` |

UART RX 回调仅在 ISR 中操作 volatile 帧缓冲，**不调用任何 FreeRTOS API**；下行帧解析在任务上下文完成。

## 6. 通信协议 v1 摘要确认

| 类别 | 阶段 0 确认结果 |
|---|---|
| 下行帧 | 只接受 `5A A5 LEN CMD PAYLOAD CRC16_LO CRC16_HI`；不支持旧版 `55 AA` 38 字节下行泵命令 |
| 上行帧 | `55 AA VER SEQ PAYLOAD_LEN PAYLOAD CRC16`，`VER=0x02`，payload 固定 30 字节，总长 38 字节，250 ms 周期 |
| 新增 CMD | `0x08` USB 灯模式，`0x09` 雾化器开关 |
| 保留 CMD | `0x01`、`0x04`-`0x07` 水泵；`0x02` 土壤配置；`0x03` 联动配置 |
| TDS 字段 | 上行 payload 偏移 11，`tds_ntu` 为 `u16 LE`，单位 NTU |
| 联动字段 | `0x03` payload 的 bit2 为 TDS 过低联动；`tds_low` 为 `u16 LE` NTU |
| 删除内容 | 压力字段、压力 alarm、WQM/WQI UART 水质模块、旧 WQI 低阈值语义 |
| alarm_flags | bit0 土壤故障；bit2 空温湿读失败；bit3 TDS 失败；bit4 水温失败；bit5 水温高；bit6 TDS 低；bit8 通信错误；bit9 USB 灯；bit10 雾化器可选 |

## 7. 初始化顺序

1. `g_common_init()` / RASC 生成外设初始化（含 `R_BSP_WarmStart` 中的 IOPORT 配置）。
2. `main_service_entry()` → `aqua_app_init()`：初始化雾化器、水泵、DS18B20、SHT30、土壤/TDS ADC、USB Host；共享状态默认值（水泵自动、PWM 60、土壤阈值 30/回差 10、水温阈值 30.0 ℃、TDS 下限 300 NTU）；水泵停止、雾化器关、USB 灯模式 `0xFF`。
3. `com_service_init()`：打开 UART，注册收发回调。
4. 进入 10 ms 主循环：`aqua_app_process_10ms()` → `com_service_process_10ms()` → `vTaskDelay(10ms)`。

## 8. 已确认结论

1. **单一任务 `main_service`（10ms 主服务）**，UART/USB Host 均并入该任务，不新增第二任务；原 `com`、`new_thread0` 线程已删除。
2. 土壤湿度与 TDS ADC 引脚按 `P001` / `P002`。
3. TDS 模块模拟输出已确认经过分压/限幅，不超过 RA8P1 ADC 允许范围。
4. USB Host 使用 RA8P1 HS 口，`P407/P408` 与 `hardware/ra8p1/demo/usb_light/` 一致；RTOS 模式下 `R_USB_Open` 必须注册非空 `p_usb_apl_callback`（拷贝 `g_basic0_cfg` 后改回调），控制传输用任务通知等待，**不能用裸机 `R_USB_EventGet` 轮询**——否则枚举到 `CONFIGURED` 即崩进 `Default_Handler`。
5. UART 改用 FSP 中断式 `write()` 发送；RX 经 char 回调入帧状态机。
