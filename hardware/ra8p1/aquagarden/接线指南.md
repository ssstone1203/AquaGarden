# AquaGarden RA8P1 接线指南

> **职责**：模块 ↔ 供电 / RA8P1 引脚对照。  
> 协议 → [`通信协议.md`](通信协议.md)；命令 → [`命令表.md`](命令表.md)；固件 → [`工程说明.md`](工程说明.md)

| 模块 | 供电 | 信号 | RA8P1 引脚 |
| --- | --- | --- | --- |
| DS18B20 | **3.3 V** + GND | DQ | `P912`（外接上拉至 3.3 V） |
| SHT30 | **3.3 V** + GND | SCL / SDA | `P410` / `P409` |
| 土壤湿度 | **5 V** + GND | AO | `ADC0_AN001` / `P001` |
| TDS 水质 | **3.3 V** + GND | A | `ADC0_AN002` / `P002` |
| 水泵 DRV8870 | **12 V**(VM) + GND | IN1 / IN2(PWM) | `P104` / `P105`（逻辑 3.3 V） |
| USB 报警灯 | **5 V** VBUS | VBUSEN / VBUS | `P407` / `P408` |
| 雾化器 | **3.3 V** + GND | CTRL | `P402` |
| UART 串口模块 | 逻辑 3.3 V + GND | TX / RX（交叉） | 见下表 |

所有电源负极与 RA8P1 **GND 共地**。

UART 与串口模块 **交叉相连**（不能同名对同名）：

| 串口模块 | 接 RA8P1 |
| --- | --- |
| RX（模块收） | `P714`（MCU TX，板子发出） |
| TX（模块发） | `P715`（MCU RX，板子接收） |
| GND | GND |
