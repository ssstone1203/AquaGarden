# AquaGarden RA8P1 固件工程说明

## 实现范围

本工程按 `需求.md`（单主服务任务版）与 `通信协议.md` v1 实现 RA8P1 侧固件集成：

- **单一 FreeRTOS 任务 `main_service`（10 ms 主服务任务）**：在同一周期内驱动传感器非阻塞状态机、传感器融合、执行器控制、USB Host、UART 下行解析与 250 ms 上行组帧。不再使用第二个常驻任务。
- `device/`：硬件驱动封装，包含 DS18B20、SHT30、土壤 ADC、TDS ADC、水泵、雾化器、USB 报警灯。
- `module/`：
  - `aquagarden_app.*`：系统状态、采集编排、控制与共享 snapshot。
  - `sensor_fusion.*`：纯联动决策逻辑（土壤/水温/TDS → 是否浇水 + 报警条件）。
  - `com_protocol.*`：协议字节布局、CRC16、下行解析/分发、上行组帧。
  - `com_service.*`：UART 物理收发（FSP 中断式收发 + RX 帧状态机）。
- `src/main_service_entry.c`：任务入口与 10 ms 主循环。

未实现且不得引入：压力传感器、WQM/WQS UART 水质模块、旧 `55 AA` 38 字节下行水泵命令、`debug_probe` 调试探针。

## 任务模型

```
main_service_entry()        // RASC 线程 main_service，优先级 2，栈 4096B
├─ aqua_app_init()          // 初始化全部 device 驱动
├─ com_service_init()       // 打开 UART，注册收发回调
└─ for(;;) 每 10ms:
   ├─ aqua_app_process_10ms()   // 传感器状态机 + 融合 + 控制 + 报警
   ├─ com_service_process_10ms()// RX 下行处理 + 每 250ms TX 上行
   └─ vTaskDelay(10ms)
```

- FreeRTOS 任务数 = 1（`com` 与 `new_thread0` 线程已在 RASC 中删除）。
- UART 通信不再是独立任务，作为主服务任务中的周期服务函数实现。

## RASC 关键配置

| 项目 | 配置 |
|---|---|
| FreeRTOS | 全局动态分配启用，工程含 `heap_4`；唯一线程 `main_service`（静态分配，priority 2，栈 4096 bytes） |
| ADC_B | `g_adc0`，Group0：VC1=`AN001/P001` 土壤，VC2=`AN002/P002` TDS |
| I2C | `g_i2c_master0`，SCL=`P410`，SDA=`P409`，SHT30 地址 `0x44` |
| UART | `g_uart0`，SCI4，TX=`P714`，RX=`P715`，115200 8N1，无流控；TXI/TEI/RXI/ERI 中断启用 |
| GPT | `g_pump_timer`，GPT1 GTIOCA=`P105`，P104 为水泵 IN1 GPIO |
| USB | `g_basic0`，USB Host，HS/IP1，VBUSEN=`P407`，VBUS=`P408` |

修改 `configuration.xml` 后需由 RASC 重新生成 `ra_gen/`。

## 通信协议

- 下行帧：`5A A5 LEN CMD PAYLOAD CRC16_LE`。
- 上行帧：`55 AA VER=0x02 SEQ LEN=30 PAYLOAD CRC16_LE`（总长 38 字节，250 ms 周期）。
- CRC 使用 Modbus CRC16，覆盖除 CRC 本身外的全部字节。
- 下行 CMD `0x01`~`0x09` 按 `通信协议.md` v1 分发到 `aquagarden_app`。

### UART 收发实现

- **上行（TX）**：`com_send_uplink()` 在任务上下文中以**寄存器轮询**方式发送（`com_uart_write_polling()`：等 `CSR.TDRE` → 写 `TDR_BY` → 清 `CFCLR.TDREC`，末尾等 `CSR.TEND`），并显式关闭 TXI/TEI 中断。38 字节 @115200 约阻塞 3.3 ms，每 250 ms 一次。
- **下行（RX）**：`UART_EVENT_RX_CHAR` 回调（ISR）逐字节进入帧状态机，识别 `5A A5` 同步头与长度，整帧拷贝到 pending 缓冲并置 `s_frame_pending`；任务侧解析。
- UART 回调（ISR 上下文）**只处理 RX 且不调用任何 FreeRTOS API**。
- **为何不用 FSP 中断式 `write()`**：实测 FSP 的 TXI/TEI 中断发送路径在本 MCU 上会在发出第 1 帧后触发 `Default_Handler`（UsageFault/INVSTATE），与 `DEBUG_RECORD.md` 记录一致；因此上行固定采用寄存器轮询。RASC 中 TXI/TEI 中断虽已生成，但运行时被 `com_disable_tx_irqs()` 关闭，不影响。

## TDS 换算

TDS ADC 使用 `P002/AN002`，电压按 0~3 V 换算，NTU 使用标准曲线：

```text
y = 66.71x^3 - 127.93x^2 + 428.7x
```

中值滤波 5 点；不使用 Arduino ppm 公式，也不做温度补偿。

## 传感器节拍与非阻塞

| 模块 | 节拍 | 阻塞情况 |
|---|---|---|
| DS18B20 水温 | 每 tick 推进；首次发起转换返回 `FSP_ERR_IN_USE`，≥750 ms 后读取 | 仅 1-Wire 时序约 1-2 ms |
| SHT30 温湿度 | 非阻塞状态机，自定速约 1 s/次（IDLE→TX→转换→RX） | 无（移除了原 20 ms `R_BSP_SoftwareDelay`） |
| 土壤 / TDS ADC | 每 40 ms 读取连续扫描锁存值 | 无 |
| USB 报警灯 | 事件经 FSP 回调（RTOS 模式）异步送达；`dev_usb_light_process()` 每 tick 仅推进 bringup 倒计时 | 仅设备枚举后 bringup 时一次性控制传输等待（约数十 ms） |

## 设备注意事项

- DS18B20 位于 `P912`，需外接上拉。
- SHT30 使用 CRC8 校验，地址 `0x44`。
- 水泵 `P104=IN1`，`P105=IN2/PWM`，VREF 不控制。
- 雾化器 `P402` 初始低电平。
- USB 报警灯通过 CH340 厂商控制传输完成串口桥初始化，并用固定 8 字节灯控帧发送模式（`mode` 范围 `0..26`）。
- **USB 在 RTOS（`BSP_CFG_RTOS==2`）下必须注册应用回调**：`R_USB_Open` 用 `g_basic0_cfg` 的副本并将 `p_usb_apl_callback` 指向 `dev_usb_light_usb_callback`；枚举/控制传输事件经该回调送达，`REQUEST_COMPLETE` 用 `xTaskNotifyGive`/`ulTaskNotifyTake` 唤醒发起控制传输的任务。**若回调为 NULL，枚举到 `CONFIGURED` 时栈会调用空指针，直接进入 `Default_Handler`。**

## 快速上手

### 编译与生成

1. 使用 Keil 打开 `aquagarden.uvprojx`。
2. 确认 RASC 使用 FSP v6.4.0；打开 `configuration.xml` 检查关键外设与唯一线程 `main_service`。
3. 执行 Keil Build：先由 RASC 生成 `ra_gen/`，再编译应用代码。
4. 若修改过 `configuration.xml`，重新生成后确认 `ra_gen/main.c` 仅 `main_service_create()`，USB 为 `USB_SPEED_HS`、`module_number=1`，ADC VC1/VC2 分别为 `ADC_CHANNEL_1`/`ADC_CHANNEL_2`。

### 烧录与接线检查

1. 按 `接线指南.md` 完成各模块接线。
2. UART 使用 `P714` TX、`P715` RX，参数 115200 8N1，与上位机交叉连接并共地。
3. DS18B20 DQ 需外接上拉；TDS 模拟输出须经分压/限幅，不超过 RA8P1 ADC 输入范围。
4. 烧录后先保持执行器电源可控，确认水泵、雾化器、USB 灯不会异常动作。

### 串口联调

1. 上电后串口助手应每 250 ms 收到一帧 `55 AA 02` 开头、总长 38 字节的上行帧。
2. 先验证 CRC16，再按 `通信协议.md` 解析温湿度、水温、土壤、`tds_ntu`、水泵 PWM、雾化器、USB 灯模式与 `alarm_flags`。
3. 发送 `0x04`/`0x05`/`0x06`/`0x07` 验证水泵启动/停止/调速/自动。
4. 发送 `0x08 mode`（`0..26`）验证 USB 灯；`0x09 00/01` 验证雾化器关/开。
5. 调整 `0x02` 土壤阈值、`0x03` 联动配置，验证自动联动与 `alarm_flags`。

### 常见现象

- `SOIL_SENSOR_FAULT` 置位：检查 `P001/AN001`、ADC 生成配置与传感器供电。
- `USB_LIGHT_FAULT` 置位：检查 USB HS 口、`P407/P408`、CH340 枚举与报警灯供电。
- 温湿度长期无更新或 `AIR_READ_FAIL` 置位：检查 SHT30 地址 `0x44`、`P410/P409` 上拉与接线。
- 串口完全收不到数据：检查 UART 交叉接线、共地，以及 RASC 中 `g_uart0` 的 TXI/TEI 中断是否启用。
