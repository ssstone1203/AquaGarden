# AquaGarden RA8P1 固件工程说明

> **职责**：固件架构、RASC 配置、任务模型、编译烧录、实现踩坑。  
> **阅读路径**：硬件接线 → [`接线指南.md`](接线指南.md)；协议规范 → [`通信协议.md`](通信协议.md)；发命令/联调 → [`命令表.md`](命令表.md)；改固件 → 本文。

## 实现范围

本工程按 [`需求.md`](需求.md)（单主服务任务版）与 [`通信协议.md`](通信协议.md) v1 实现 RA8P1 侧固件集成：

- **单一 FreeRTOS 任务 `main_service`（10 ms）**：传感器非阻塞状态机、融合、执行器、USB Host、UART 上下行。
- `device/`：DS18B20、SHT30、土壤 ADC、TDS ADC、水泵、雾化器、USB 报警灯。
- `module/`：`aquagarden_app.*`、`sensor_fusion.*`、`com_protocol.*`（应用层）、`com_service.*`（UART 传输层）。
- `src/main_service_entry.c`：任务入口。

未实现且不得引入：压力传感器、WQM/WQS、旧 `55 AA` 下行泵命令、`debug_probe`。

## 任务模型

```
main_service_entry()        // RASC 线程 main_service，优先级 2，栈 4096B
├─ aqua_app_init()
├─ com_service_init()
└─ for(;;) 每 10ms:
   ├─ aqua_app_process_10ms()
   ├─ com_service_process_10ms()
   └─ vTaskDelay(10ms)
```

FreeRTOS 应用任务数 = 1（`com`、`new_thread0` 已在 RASC 删除）。

## RASC 关键配置

| 项目 | 配置 |
|---|---|
| FreeRTOS | 动态分配 + `heap_4`；唯一线程 `main_service`（静态，priority 2，栈 4096 B） |
| ADC_B | `g_adc0`，VC1=`AN001/P001` 土壤，VC2=`AN002/P002` TDS |
| I2C | `g_i2c_master0`，SCL=`P410`，SDA=`P409`，SHT30 `0x44` |
| UART | `g_uart0`，SCI4，TX=`P714`，RX=`P715`，115200 8N1 |
| GPT | `g_pump_timer`，GPT1 GTIOCA=`P105`，IN1=`P104` |
| USB | `g_basic0`，Host HS/IP1，VBUSEN=`P407`，VBUS=`P408` |

修改 `configuration.xml` 后须 RASC 重新生成 `ra_gen/`。

## 通信协议（摘要）

应用层规范见 [`通信协议.md`](通信协议.md)；上位机 HEX 与联调见 [`命令表.md`](命令表.md)。

- 下行：`5A A5 LEN CMD PAYLOAD CRC16` → `com_protocol` 解码 → `aquagarden_app`
- 上行：`55 AA VER=0x02` + 30 B Payload + CRC16，总长 38 B，250 ms 周期
- CMD `0x01`~`0x09`；Modbus CRC16；无下行 ACK

### UART 收发实现（传输层）

- **TX**：`com_uart_write_polling()` 寄存器轮询；显式关闭 TXI/TEI。38 B @115200 约 3.3 ms，每 250 ms 一次。
- **RX**：`UART_EVENT_RX_CHAR` ISR 逐字节定界 `5A A5`；任务侧 `com_downlink_decode` + `com_apply_downlink`。
- **不用 FSP `write()` + TX 中断**：会触发 `Default_Handler`（见 [`DEBUG_RECORD.md`](DEBUG_RECORD.md)）。

## TDS 换算

ADC `P002/AN002`，0~3 V → NTU，公式见 [`接线指南.md`](接线指南.md) §4。固件：5 点中值滤波，无温度补偿。

## 传感器节拍与非阻塞

| 模块 | 节拍 | 阻塞 |
|---|---|---|
| DS18B20 | 每 tick 推进；≥750 ms 读一次 | 1-Wire 时序约 1–2 ms |
| SHT30 | 状态机，约 1 s/次 | 无 |
| 土壤 / TDS ADC | 每 40 ms | 无 |
| USB 灯 | FSP 回调送事件；`process()` 仅 bringup 倒计时 | 枚举后 bringup 一次性控制传输（数十 ms） |

## 设备注意事项

- DS18B20 `P912`，外拉上拉；SHT30 CRC8，地址 `0x44`。
- 水泵 `P104`/`P105`；雾化器 `P402` 初始低。
- USB：RTOS 下须拷贝 `g_basic0_cfg` 并注册 `dev_usb_light_usb_callback`；`REQUEST_COMPLETE` 用任务通知。NULL 回调 → 枚举时 `Default_Handler`。

## 快速上手

### 编译与生成

1. Keil 打开 `aquagarden.uvprojx`；FSP v6.4.0。
2. 检查 `configuration.xml` 与唯一线程 `main_service`。
3. RASC 生成 `ra_gen/` 后 Build。
4. 改 RASC 后确认 `ra_gen/main.c` 仅 `main_service_create()`。

### 烧录与接线

1. 按 [`接线指南.md`](接线指南.md) 接线。
2. UART `P714`/`P715`，115200 8N1，交叉、共地。
3. TDS AO 分压/限幅；烧录后注意执行器安全。

### 串口联调

步骤、完整 HEX、自检序列见 [`命令表.md`](命令表.md) §8。

### 常见现象

- `SOIL_SENSOR_FAULT`：查 `P001/AN001`、ADC 配置。
- `USB_LIGHT_FAULT`：查 USB HS、`P407/P408`、CH340 枚举。
- `AIR_READ_FAIL`：查 SHT30 `0x44`、`P410/P409`。
- 串口无数据：查交叉接线、共地、`g_uart0` 配置。
